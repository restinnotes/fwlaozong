# 丘脑底核神经活动与帕金森病冻结步态的关系：现有证据、争议机制与可检验研究框架

**研究领域：** 功能神经外科、脑深部电刺激（deep brain stimulation, DBS）、丘脑底核（subthalamic nucleus, STN）、帕金森病（Parkinson’s disease, PD）及冻结步态（freezing of gait, FOG）。

**证据截止日期：** 2026年11月13日。

**报告类型：** 结构化叙述性证据综合（structured narrative evidence synthesis），不是按照 PRISMA 方案预注册和双人独立筛选的系统综述，也不是 Meta 分析。

## 摘要

### 研究背景

冻结步态（FOG）是帕金森病的重要轴性运动障碍之一，也是STN-DBS治疗后仍可能持续存在、改善不充分或出现恶化的临床问题。STN既是PD运动环路的重要节点，也是临床可直接记录和干预的神经外科靶点，因此STN神经活动与FOG之间的关系具有基础神经科学和临床治疗双重价值。

然而，目前相关研究呈现出一个重要现象：**STN神经活动与FOG之间存在较明确的关联证据，但不同研究观察到的神经活动方向、频段、时间结构及其与实际冻结事件的关系并不一致。**

例如：

- 患者层面的研究发现，FOG患者可能具有较高的STN高beta活动。
- 部分实际冻结事件研究发现，冻结期间STN beta功率下降或没有显著变化。
- 转弯冻结研究则观察到低beta活动增加，以及相对于站立状态的低beta ERD缺失。
- 同步EEG-STN记录发现，冻结前及冻结期间皮层-STN theta-alpha耦合下降，但STN局部功率并没有相应显著变化。
- beta burst的平均持续时间、长burst比例及其时间分布，在不同任务中也呈现不同结果。

这些现象并不必然意味着研究互相否定。患者易感状态、步态周期内的动态调节、实际冻结事件和冻结后的运动停止，可能对应不同的生理过程。

### 核心结论

本报告的总体判断是：

**STN相关网络参与FOG的发生或调节，并具有临床可干预性；但是，目前尚不能证明某种STN内源性神经活动是FOG发生的必要或充分原因，也不能建立一个适用于所有FOG患者的统一STN电生理标志。**

该判断由三条证据链构成：

1. **临床干预证据：** STN-DBS能够改变部分患者的FOG结局，但疗效具有患者、药物状态、刺激参数、刺激位置和随访时间依赖性。
2. **人体电生理证据：** STN-LFP、MUA、单单位放电及皮层-STN耦合研究观察到了与FOG易感性或实际冻结相关的神经活动变化。
3. **因果识别证据：** 现有研究尚未完成对候选STN内源活动的选择性操控、上下游网络同步记录、时间先后验证及真实冻结结局中介验证。

因此，需要严格区分：

- STN是否参与FOG；
- STN活动是否与FOG相关；
- STN活动是否先于FOG；
- STN活动是否直接导致FOG；
- 改变STN活动是否通过特定神经机制改善FOG。

这五个问题的证据强度并不相同。

<text color="secondary" size="xs">核心证据状态：C1（跨研究综合，支持）；N1（跨研究综合，初步支持）；N2（跨研究综合，存在争议）；N3（因果证据不足）。</text>

### 1.3 证据分层与判定规则

本报告使用以下五个层级。

| 层级 | 定义 | 可以支持的判断 |
|---|---|---|
| 原始证据 | 原始实验、临床试验、队列及电生理记录 | 特定条件下实际观察到的结果 |
| 单项研究发现 | 对单项原始研究结果的概括 | 某研究支持或不支持某个关联 |
| 跨研究综合结论 | 对多个研究的共同点及冲突进行综合 | 证据是否重复、稳定及适用范围 |
| 机制模型 | 对可能因果路径的组织性解释 | 提出变量间可能的因果关系 |
| 研究假说 | 具有区分性预测和反证条件的机制命题 | 指导后续实验检验 |

重要结论进一步标注：

- **直接证据：** 原始研究直接观察或操控了所讨论的变量。
- **跨研究推断：** 多项研究的结果经过综合后得到的判断。
- **假说：** 目前尚未得到直接实验验证的机制解释。

不能因为某种解释被多篇综述引用，或被多个机制模型共同采用，就将其提升为已经得到实验验证的结论。

两条证据链可以相互补充，但不能互相替代。

例如，刺激开启后FOG减少，说明刺激能够改变与冻结有关的系统状态，却不能据此证明刺激通过抑制STN高beta活动发挥作用。反过来，即使某种STN活动与FOG高度相关，也不能直接证明改变该活动能够改善冻结。

**综合判断：C1支持；N3限制其因果解释。**

### 2.2 患者层面：FOG易感性与STN活动的关系

患者层面的研究主要回答：

> 为什么某些PD患者更容易发生FOG，而另一些患者没有明显冻结？

这一层级主要涉及病例对照、静息态LFP以及未发生实际冻结的受控步态任务。

**证据一：STN高beta活动与FOG患者表型相关。**

Toledo等的病例对照研究纳入22例PD患者，其中FOG组14例、非FOG组8例。研究发现：

- FOG组STN高beta功率高于非FOG组（F=11.6，p=0.002）。
- 左旋多巴给药后，高beta活动下降，同时FOG受到抑制。
- 高beta皮层-STN相干性主要表现为中线皮层电极处较强的相干性。

该研究支持患者层面的高beta异常与FOG表型相关，但没有充分证明高beta活动在每次实际冻结之前出现。[PMID:24361601]

**证据状态：直接证据（患者间关联及药物状态相关变化）；不能视为冻结事件的因果证据。**

**证据二：静息alpha及间歇性alpha、高beta活动与FOG严重程度相关。**

Neto等2025年的研究纳入23例患者，其中FOG组14例、非FOG组9例，记录静息STN-LFP。

主要发现：

- FOG组alpha功率高于非FOG组（0.331±0.087 vs 0.248±0.089，p=0.011）。
- 间歇性alpha活动幅度也更高（p=0.005）。
- 间歇性alpha幅度与FOG评分相关（r=0.330，p=0.046）。
- 间歇性高beta幅度与FOG评分相关（r=0.415，p=0.011）。

这些结果提示，FOG相关的STN活动可能不局限于beta频段。[PMID:39884164]

**证据状态：直接证据（静息态患者间差异及严重程度关联）；不能直接推广到真实冻结期间。**

**证据三：beta burst时间结构可能与FOG易感性相关。**

Anidi等的研究纳入12例患者（8名Freezers、4名Non-Freezers），发现Freezers在未发生冻结的原地踏步和前向行走阶段，STN beta burst持续时间较长。[PMID:30196050]

值得注意的是，该研究还发现：

- 双侧STN平均beta burst持续时间的差异与双腿stride time差异存在强相关（r=0.853，p=0.002）。
- 该关联发生在没有实际冻结的步态周期中。

这说明STN beta时间结构可能与患者的步态协调状态有关，但不能证明长burst本身导致冻结。

**证据状态：直接证据（患者表型及步态参数关联）；对FOG因果机制的支持仍有限。**

**证据四：beta活动和复杂度指标的结果受到任务范式影响。**

Syrkin-Nikolau等研究纳入14例患者，其中8名Freezers、6名Non-Freezers。其结果显示：

- 在无FOG的原地踏步期间，Freezers的beta SampEn高于Non-Freezers。
- 这一差异没有在无FOG的前向行走期间重复出现。
- FOG发生期间，alpha SampEn高于无FOG行走期间。
- 不同任务下beta功率与beta SampEn存在明显关系。

这项研究的重要贡献不只是发现熵变化，而是说明同一STN信号的特征可能因任务和运动状态不同而改变。[PMID:28890315]

**证据状态：直接证据（任务依赖的信号特征）；尚不能建立稳定的FOG特异性复杂度标志。**

### 2.3 实际冻结事件：神经活动在什么时候发生变化？

这一层级是判断STN是否参与FOG发生过程的关键，因为它能够部分解决患者间差异与单次事件之间的混淆。

目前需要分别考察：

1. 冻结前（pre-FOG）：异常是否先于运动停止？
2. 冻结开始（FOG onset）：是否存在事件启动相关变化？
3. 冻结持续（FOG episode）：是否存在维持冻结的活动？
4. 恢复（recovery）：神经活动是否随正常行走恢复？

**研究A：前向行走冻结中的局部beta功率没有显著变化。**

Pozzi等2019年的研究是这一方向的重要人体证据。

<badge color="info">实际冻结事件同步记录</badge>

- 7名接受双侧STN-DBS的患者。
- 其中5名FOG阳性患者，共记录14次冻结事件。
- 患者处于Med-Off、Stim-Off状态。
- 比较有效行走、冻结前1.5秒、冻结开始、冻结结束及冻结后阶段。

结果：

- 冻结期间STN局部beta功率相对于有效行走没有显著变化。
- 双侧STN beta耦合在冻结开始时有增加趋势，冻结结束时有下降趋势，但均未达到统计学显著性。
- 与此相反，SMA、M1及顶叶与同侧STN之间4–13 Hz theta-alpha耦合，在冻结前约1.5秒已经下降。
- 这种耦合下降持续到冻结阶段，并在恢复正常行走后重新建立。

因此，该研究最值得重视的发现不是局部beta功率升高，而是**冻结前已经出现的皮层-STN低频耦合下降**。[PMID:31505548]

<text color="secondary" size="xs">证据状态：直接事件级电生理观察。样本仅7人、14次事件；所有冻结均为接近门道时诱发的前向行走冻结，不能推广至所有FOG类型。</text>

**研究B：转弯冻结可能伴随低beta去同步化失败。**

Klocke等2026年的研究（预印本）纳入13名患者，其中11名在转弯过程中发生FOG。

<badge color="info">实际转弯冻结事件</badge>

研究在Med-Off/Stim-Off条件下同步记录STN-LFP与步态运动学，包含：

- 122次冻结转弯；
- 224次正常转弯；
- 1191个正常步态周期。

主要发现：

1. 正常转弯和正常行走期间，STN低beta、alpha及高beta均出现相对于站立状态的去同步化。

4. 转弯前阶段已经存在低beta调节异常，但直接比较Pre FoG-Turn与Pre Reg-Turn时，频谱差异没有达到统计学显著性。

### 2.4 不同研究结果的主要比较

<text color="secondary" size="xs">下表比较的是研究层级、任务及神经活动指标，而不是将不同指标视为同一变量。</text>

| 研究条件 | STN活动发现 | 对FOG的解释 |
|---|---|---|
| 患者间病例对照 | 高beta增加 | 可能反映易感性 |
| 静息LFP | alpha及间歇性活动增加 | 可能反映疾病表型 |
| 未冻结原地踏步 | beta burst延长、SampEn变化 | 可能反映潜在易感状态 |
| 前向行走实际冻结 | beta功率无显著变化 | 不支持统一的冻结期beta升高 |
| 门道诱发冻结前后 | theta-alpha皮层-STN耦合下降 | 支持网络耦合失稳 |
| 转弯实际冻结 | 低beta ERD缺失 | 支持步态相位调节异常 |
| 转弯冻结开始 | PMC-STN alpha增加、M1-STN alpha下降 | 支持脑区依赖的连接变化 |
| 术中VR任务 | 认知提示后MUA短暂增加 | 提示认知负荷与STN活动相关 |
| 原地踏步中的freezing-like状态 | STN beta振荡增强 | 不能直接等同于自然步行FOG |

**这里最重要的综合结论是：STN与FOG之间可能存在多层次神经动力学关系，而不是简单的“冻结时STN活动升高”或“冻结时STN活动降低”。**

**证据状态：跨研究推断（N1、N2、C11、C13、C14、C17）。**

### 2.5 其他电生理与网络证据：不能忽略的测量层级

除LFP功率外，人体研究还提供了MUA、单单位放电及跨脑区信号的补充证据。

**（1）STN MUA与认知负荷下的步态异常**

Georgiades等2023年的术中研究纳入8名患者，分析33次认知提示试次，其中15次出现冻结或明显步态减速。

在随后发生冻结或显著减速的试次中，认知提示与第一个提示后脚步之间出现STN MUA放电率短暂升高。[PMID:37226972]

但该研究采用仰卧虚拟现实步态任务，且将冻结和显著减速试次合并。因此：

- 支持认知运动转换过程中STN多单位活动发生变化。
- 不能证明MUA升高特异于真实FOG。
- 不能证明MUA升高是实际冻结的起始原因。

**证据状态：直接人体神经记录；真实行走FOG的外部效度有限。**

**（2）STN单单位放电与freezing-like运动状态**

Gulberti等2023年通过术中微电极记录研究STN及黑质神经元。

研究纳入12例患者，记录113个稳定STN神经元，并在原地踏步过程中分析正常踏步与作者定义的freezing-like stepping irregularities。

研究发现：

- 正常踏步期间STN beta振荡活动下降。
- freezing-like运动不规则期间，beta振荡活动相对于正常踏步增强。
- STN与黑质神经元对步态状态的调节并不相同。

这一发现支持STN参与步态状态转换，但其freezing-like行为定义不是自然步行中的临床真实FOG，不能将两者等同。[PMID:36730026]

**证据状态：直接人体单单位及多单位记录；对真实FOG的特异性证据有限。**

**（3）STN以外的脑干电生理证据**

Fraix等2013年对7名植入PPNa电极的PD伴严重FOG患者进行记录。

药物OFF时，患者在原地踏步中出现冻结；药物ON后，FOG占任务时间的比例由61.7±36.1%下降至7.3±10.1%。与此同时，PPNa的alpha活动增加，beta及gamma活动降低。[PMID:24386308]

这项研究并非STN记录，却具有重要的机制意义：

- FOG改善可以伴随STN以外脑干区域的神经活动改变。
- 不能将所有与冻结相关的神经动态都归因于STN局部活动。
- PPNa与STN之间是否存在直接中介关系，仍未得到验证。

**证据状态：直接脑干电生理观察；不能作为STN局部神经活动的直接证据。**

**（4）脑影像与分布式网络证据**

认知负荷步行的fMRI研究发现，FOG患者在执行间接认知指令时，对STN、前岛叶、腹侧纹状体及辅助运动前区的招募不足。[PMID:23382821]

另一项事件相关fMRI研究发现，实际冻结期间STN及部分基底节区域的BOLD响应降低。[PMID:23485851]

143例PD患者的PET研究则发现，新皮质胆碱能神经支配降低与FOG发生相关；当新皮质胆碱能病变和研究所考察的额外黑质病理条件同时存在时，FOG发生率更高。[PMID:24909584]

这些研究提示FOG可能涉及皮层、基底节、脑干及非多巴胺能系统的共同作用。

必须注意，BOLD、PET血流或代谢变化不等于单神经元放电变化，也不能直接确定网络的信息传递方向。

**证据状态：直接影像学或临床观察证据；分布式网络机制属于跨研究推断。**

### 2.6 STN beta burst之外的时间复杂度：一个值得单独追踪的新方向

除平均功率和burst持续时间外，近年来开始出现对beta burst时间分布、熵和非线性复杂度的研究。

这类研究值得单独建立证据分支，因为不同复杂度指标并不具有相同定义。

尤其值得注意的是2026年的一项预印本二次分析：

Beaudoin等使用4名患者的既有STN-LFP数据，分析176次FOG事件，其中163次（92.6%）前存在转弯。

研究发现：

- FOG发生前的转弯中，STN beta burst timing的Shannon entropy低于稳定转弯。
- 低beta与高beta均出现这一差异。
- 患者层面的leave-one-patient-out分类中，Shannon entropy模型AUC为0.825。
- 但FOG实际发生期间与pre-freeze转弯之间，Shannon entropy没有显示同样的显著区分能力。
- 同一分析中，Lempel-Ziv complexity反而增加。

[DOI:10.64898/2026.08.13.744293]

这一结果不能直接概括为“FOG时STN熵降低”，因为研究最明确的结果是**冻结前转弯的beta burst时间分布发生变化**，而且不同复杂度指标的变化方向并不相同。

它还带来一个重要问题：2017年研究观察到的alpha Sample Entropy增加、2026年研究观察到的beta burst Shannon entropy降低，是否代表不同频段、不同任务阶段和不同时间结构的独立变化？

目前不能把两者合并为统一的“STN熵增加”或“STN熵下降”机制。

**证据状态：直接观察性二次分析；探索性预测证据，尚缺独立患者队列验证。**

## 三、临床STN-DBS干预证据：为什么疗效研究也存在冲突？

### 3.1 总体疗效：部分患者改善，但不是普遍获益

现有临床证据不支持“STN-DBS一定改善FOG”，也不支持“STN-DBS普遍加重FOG”。

更合理的判断是：STN-DBS能够改善部分患者的冻结，但疗效具有显著的患者异质性。

**EARLYSTIM二次分析：较大样本随机试验提供的阳性证据。**

Barbe等对EARLYSTIM随机试验进行二次分析，纳入251名患者，比较STN-DBS联合最佳药物治疗与单独最佳药物治疗，随访24个月。

基线时，两组均有52%的患者存在FOG。

24个月时：

- STN-DBS组FOG比例下降至34%。
- 最佳药物治疗组没有出现相同变化。
- 组间差异P=0.018。
- 刺激组完成步态测试所需步数也有改善（P=0.016）。

该结果支持STN-DBS在特定PD人群中能够改善FOG，但这是随机试验的二次分析，并非以真实冻结事件的同步STN电生理记录为主要研究目的。[PMID:31755599]

**证据状态：直接临床干预证据；对STN内源活动中介的支持有限。**

<FileCite ref="turn1file0"/>

**Ferraye等123例连续病例研究：左旋多巴反应性与STN刺激反应相关。**

研究纳入123例患者，术前及术后1年比较药物和刺激状态。

主要发现：

- 对多数术前存在左旋多巴反应性FOG的患者，STN刺激能够重现术前左旋多巴带来的冻结改善。
- 只有少数患者未能重现这一改善。
- 11名患者在术后首次出现FOG或无法完成步行测试。

该研究支持术前FOG表型及药物反应性可能影响术后冻结结局。[PMID:18413568]

**证据状态：直接临床观察及治疗状态比较；非随机的刺激中介机制验证。**

**Vercruysse等41例前瞻性对照队列：疗效判断受到LED影响。**

研究比较24例STN-DBS患者与17例持续最佳药物治疗患者。

在基线存在FOG的患者中：

- 6个月时，STN-DBS组的NFOG-Q严重程度低于药物治疗组。
- 12个月时仍然观察到组间差异。
- 但控制基线左旋多巴等效剂量（LED）后，组别与时间交互作用不再显著。

其探索性分析还发现，20名基线freezer中，12个月时11名转变为non-freezer，9名仍为freezer；冻结改善与LED下降及UPDRS IVb运动波动改善相关。

然而，这些结果不能证明药物剂量变化是STN-DBS抗冻结疗效的因果中介。[PMID:24396010]

**证据状态：直接临床队列证据；药物中介解释属于跨研究推断。**

<FileCite ref="turn4file8"/> <FileCite ref="turn4file6"/>

**Fan等76例回顾性研究：患者间差异明显。**

研究纳入76例高频STN-DBS患者：

| 术后FOG结局 | 患者数 | 比例 |
|---|---:|---:|
| 改善 | 42 | 55.3% |
| 变化轻微 | 22 | 28.9% |
| 恶化 | 12 | 15.8% |

总体FOG-Q从16.89±5.46下降至10.05±7.16，P小于0.001。

这说明平均改善并不意味着每个患者都获益。研究也报告了刺激位置与冻结改善之间的关联，后文进一步讨论。[PMID:37701817]

**证据状态：直接临床观察；回顾性设计，存在选择偏倚。**

<FileCite ref="turn4file3"/>

### 3.2 重要的阴性结果：改善一般步态不等于减少冻结

Cowie等2012年的门道诱发实验值得特别重视。

研究纳入10名PD-freezers及10名对照，比较四种治疗状态：

- Med-Off/Stim-Off；
- Med-Off/Stim-On；
- Med-On/Stim-Off；
- Med-On/Stim-On。

研究发现，窄门增加freeze-like events发生风险，左旋多巴降低冻结风险，但STN-DBS没有观察到相同的冻结风险降低。[PMID:21997389]

这一结果与一些报告STN-DBS能够改善FOG的研究存在表面冲突。

但必须注意，Cowie研究测量的是门道诱发的freeze-like events，而不是所有日常生活中的自发性FOG；它也不能证明STN-DBS在其他任务中完全没有抗冻结作用。

**证据状态：直接实验性行为证据；特定情境下的阴性结果。**

<FileCite ref="turn6file1"/>

### 3.3 延迟性恶化与新发FOG：不能简单归因于刺激

临床上至少需要区分五种不同情形：

1. 植入后、刺激开启前出现新发FOG；
2. 刺激开启后立即出现FOG；
3. 参数或触点调整后出现FOG变化；
4. 长期刺激过程中出现延迟性FOG或OFF期步态恶化；
5. PD自然病程进展及其他因素导致的FOG变化。

Mei等的单病例报告提供了一个典型的药物-刺激交互例子：

- 患者术前主要表现为OFF-FOG，左旋多巴能够改善冻结。
- 术后单独开启STN刺激时，FOG评分由4降至2。
- 单独使用左旋多巴时，FOG评分由4降至1。
- 联合左旋多巴和高频STN刺激后，却出现新发且持续的ON-FOG，评分由2升至4。
- 随后通过药物和刺激参数共同调整，FOG有所改善。

该病例说明治疗组合可能产生非加和效应，但不能据此推断这种情况具有普遍性。[PMID:31275238]

**证据状态：单病例直接临床观察；机制解释属于假说。**

<FileCite ref="turn12file0"/>

长期随访也需要谨慎解释。

Krack等49例患者的5年随访发现，虽然药物OFF状态下总体运动功能仍较基线改善，但冻结步态、运动不能、言语和姿势稳定性等症状在术后第1年至第5年间出现恶化。[PMID:14614167]

因此：

- 早期DBS有效与长期FOG恶化可以同时成立。
- 长期恶化不能自动解释为刺激导致。
- 缺乏未手术同期对照时，很难将疾病进展、药物调整和刺激效果衰减分开。

**证据状态：直接纵向临床观察；长期因果归属不足。**

### 3.4 刺激频率：低频是否更有利于FOG？

目前没有确立单调的频率-疗效关系，也没有得到适用于所有患者的统一最佳频率。

现有证据主要分为三类。

**第一类：低频刺激在选择性患者中具有阳性效果。**

13例长期接受STN-DBS且存在FOG的患者研究，经随机、双盲交叉参数比较，报告60 Hz等效能量刺激优于130 Hz条件；60 Hz高电压条件获得较好的冻结结局，而130 Hz提高电压可能使步态恶化。

这项研究由后续mini-review总结，患者均为高频刺激下仍有轴性症状的选择性人群。[PMID:28529730]

**第二类：低频刺激并非总能产生客观步态优势。**

Phibbs等随机盲法交叉研究纳入20例患者，19例完成，比较60 Hz与130 Hz刺激，并保持电压、脉宽等参数不变。

研究没有发现60 Hz在主要客观步态指标上的显著优势。只有7名患者将冻结列为主要步态问题，且多数患者没有在实验室重现其主要症状。[PMID:24165197]

**第三类：Meta分析结果不一致。**

| 研究 | 主要结果 | 关键限制 |
|---|---|---|
| 频率Meta分析，2018 | 低频相较高频的FOG-Q改善，合并效应量−6.52 | FOG相关研究仅4项，部分研究未纳入合并 |
| 网络Meta分析，2025 | 不同DBS模式均未显示FOG-Q显著改善 | 25项RCT整体中，FOG-Q网络仅涉及10项研究，异质性较高 |
| 更新Meta分析，2026 | 总体FOG-Q下降2.99分；Med-Off/Stim-On比较改善更明显 | 包含不同靶点和刺激模式，不能将总体效应完全归因于STN |

对应文献：[PMID:30262859]、[PMID:41659700]、[PMID:42098512]。

需要特别指出：网络Meta分析中60 Hz-STN-DBS未达到统计学显著性，并不等于证明60 Hz完全没有临床价值。更新Meta分析的总体阳性结果也不能证明低频刺激通过STN局部beta抑制改善冻结。

**证据状态：直接临床参数比较与跨研究综合；刺激频率效应具有明显条件依赖性。**

### 3.5 刺激空间位置：是否存在抗冻结sweet spot？

Fan等76例回顾性研究发现，FOG改善组与恶化组的右侧STN激活接触点位置存在差异。改善与右侧背外侧STN位置相关，而恶化组更多位于腹内侧中央区域。[PMID:37701817]

另一项10例随机双盲交叉研究，在严重术前FOG患者中比较中心STN与后部感觉运动STN刺激，发现中心刺激的FOG发生概率较低。[PMID:39475137]

两项研究不能直接合并为同一个空间定位结论：

- 一个是回顾性最佳触点分析。
- 一个是短时间患者内交叉干预。
- 二者的解剖分区、VTA估计及患者选择标准不同。

目前最合理的解释是：刺激空间募集可能影响FOG疗效，但尚未形成统一、可外部验证的三维sweet spot。

**证据状态：直接位置相关或位置干预证据；跨研究定位共识尚未建立。**

### 3.6 自适应DBS：beta反馈是否具有特殊治疗价值？

Wilkins等2025年的随机双盲急性研究纳入7名患者，比较：

- 连续DBS（cDBS）；
- beta burst duration驱动的自适应DBS（aDBS）；
- 随机自适应刺激（rDBS）；
- 刺激关闭。

在原地踏步和自由行走任务中，部分患者的冻结时间占比在刺激开启后下降。

但最关键的结果是：**beta burst驱动的aDBS没有显著优于连续DBS或随机自适应刺激。** [PMID:40677701]

因此，该研究支持刺激开启能够改变部分患者的冻结结局，却没有证明beta burst反馈本身具有独立于刺激强度和时间组织的临床优势。

还需要考虑：

- 只有少数患者在实验中实际发生冻结。
- 同一研究的预印本和正式版不能重复计数。
- 急性实验室效果不能替代长期自然生活效果。
- 刺激幅度变化能够缩短beta burst，不等于burst缩短就是抗冻结疗效的中介。

**证据状态：直接小样本干预证据；闭环机制特异性证据较弱。**

### 3.7 STN-SNr联合刺激：重要的网络干预证据，但不能反推STN局部病因

STN-SNr联合刺激是判断FOG是否具有多节点可干预性的一个重要交叉方向。

Weiss等2013年的12例随机交叉研究报告，联合刺激改善FoG-AC评分，但预先设定的主要轴性运动终点没有相应显著改善。[PMID:23757762]

后续研究仍存在分歧：

- 2026年一项Meta分析纳入6项研究、86名患者，未发现联合刺激相较单独STN刺激有明确额外FOG获益，I²=85.6%，GRADE确定性极低。[PMID:42909654]
- 另一项纳入8项交叉RCT、97名患者的Meta分析报告双靶点刺激能够降低FOG严重程度。[PMID:42968793]
- 45例多中心随机双盲研究中，STN与STN+SNr组的主要FoG-AC终点没有显著差异，调整后组间差异为−1.16分，P=0.692。[PMID:42860886]

这组证据具有两个含义：

第一，FOG可能受到STN以外运动网络节点的临床调节。

第二，双靶点刺激的临床效果不能作为STN局部神经活动致病性的证明。

**证据状态：直接临床干预证据存在；额外疗效尚有争议。**

## 四、研究结果之间的冲突：为什么相同的STN会表现出不同方向的异常？

本领域最值得解决的问题不是哪一篇论文正确，而是不同研究究竟测量了什么，以及它们是否在检验同一个机制。

目前至少存在六类冲突。

### 4.1 平均beta功率与事件级beta变化并不相同

这是最常被误解的一组结果。

| 证据 | 观察结果 | 实际回答的问题 |
|---|---|---|
| Toledo病例对照研究 | FOG组高beta较高 | 患者间是否存在高beta表型？ |
| Neto静息态研究 | alpha及间歇性高beta活动较高 | 静息神经活动是否与FOG严重程度相关？ |
| Pozzi前向行走冻结 | 实际冻结期间beta功率无显著变化 | 冻结事件是否伴随平均beta功率变化？ |
| Klocke转弯冻结 | 低beta ERD缺失，特定低beta活动较高 | 转弯过程中beta是否正常进行运动相关调节？ |
| Anidi步态研究 | Freezers的beta burst持续时间较长 | 易冻结患者是否存在不同的beta时间结构？ |

这些结果并不直接互相否定。

例如，一个患者可以在静息状态下具有较高的高beta功率，但在实际步行冻结期间并不表现为beta平均功率持续升高。

其可能的解释包括：

1. 静息高beta反映患者长期的运动环路易感状态。
2. 步态周期性ERD反映运动过程中STN对正常步态节律的动态调节。
3. 实际冻结期间的beta变化反映冻结发生后的状态转换。
4. 平均功率可能掩盖短时间内的burst重组。

**跨研究推断：平均beta功率不是一个能够统一描述FOG全过程的生理变量。**

**仍待验证：高beta易感状态是否通过步态相位调制失败或burst时间结构异常转化为实际冻结。**

### 4.2 比较基线不同，可以使同一研究呈现不同方向的结果

Klocke等2026年转弯研究是这一问题的典型例子。

研究发现：

- FoG-Turn相对于Standing，表现为低beta ERD缺失。
- FoG-Turn相对于Regular Turn，12–15 Hz低beta活动增加。
- Pre FoG-Turn相对于Standing，也可以观察到低beta调节异常。
- 但Pre FoG-Turn与Pre Reg-Turn直接比较，没有得到显著的频谱差异。

这里至少涉及三种不同的问题：

- 冻结转弯是否与静止站立不同？
- 冻结转弯是否与正常转弯不同？
- 冻结前的转弯是否能够区分未来发生冻结和不发生冻结的试次？

前两种比较不能替代第三种。

特别是，**相对于站立状态出现异常，并不自动意味着该指标能够预测下一次冻结。**

这对后续FOG生物标志物研究具有直接的方法学意义。

### 4.3 beta burst持续时间与burst时间分布并不等价

不同研究中，beta burst结果出现了三种表现：

1. Freezers在未冻结的步态周期中，平均burst持续时间较长。
2. 前向行走真实冻结期间，平均burst持续时间没有显著增加。
3. 转弯冻结研究中，平均持续时间未表现为统一延长，但长短burst比例及其时间分布发生变化。

这三类发现可以同时成立。

例如，假设两个条件具有相同的平均burst持续时间，但一个条件中长burst比例增加、短burst比例下降，则其平均值可能几乎不变，而时间结构已经发生改变。

因此，未来研究至少应该区分：

- 平均burst持续时间；
- 长burst比例；
- 短burst比例；
- burst发生率；
- 累计burst占据时间；
- inter-burst interval；
- burst持续时间分布；
- 步态相位锁定的burst调制。

不能将所有结果简化为“长burst增加”或“beta同步增强”。

**跨研究推断：beta burst时间结构可能比平均功率更接近部分FOG相关过程，但尚未建立普遍适用的冻结标志。**

### 4.4 熵和复杂度结果的方向冲突，可能是不同生理变量被错误合并

现有证据涉及：

- Sample Entropy；
- Shannon entropy；
- Permutation entropy；
- Lempel-Ziv complexity；
- Hjorth复杂度；
- inter-burst interval变异系数；
- median absolute deviation。

它们不是同一种数学指标。

目前至少存在以下不同观察：

| 研究 | 指标 | 结果 |
|---|---|---|
| Syrkin-Nikolau 2017 | beta SampEn | SIP期间Freezers高于Non-Freezers |
| Syrkin-Nikolau 2017 | alpha SampEn | 实际FOG期间高于无FOG行走期间 |
| Beaudoin 2026 | beta burst Shannon entropy | 冻结前转弯低于稳定转弯 |
| Beaudoin 2026 | Lempel-Ziv complexity | 冻结前转弯反而升高 |

参考：[PMID:28890315]、[DOI:10.64898/2026.08.13.744293]。

这里存在两组不同的竞争性解释：

**解释A：病理性信息失序。**

冻结前神经时间结构变得异常，导致感觉运动信息处理不稳定。

**解释B：代偿性信息重组。**

冻结发生后，神经系统增加信息募集和控制复杂度，以维持运动或促进恢复。

还存在第三种可能：不同指标反映的是不同的时间组织属性，而非同一种“复杂度”的正反方向。

因此，H11和H12不能仅根据某个熵指标升高或下降来决定支持与否。

必须在同一患者、同一任务中同步比较冻结前、冻结中、恢复阶段，并预先指定每种复杂度指标的计算方式。

### 4.5 皮层-STN耦合的变化具有脑区依赖性

Pozzi研究发现SMA、M1和顶叶与STN之间的theta-alpha耦合在冻结前下降。

Zhang研究则发现：

- PMC-STN alpha coherence增加；
- M1-STN alpha coherence下降。

这提示不能把所有皮层-STN连接合并为一个整体变量。

更合理的研究单位是：

\[
\text{脑区}\times\text{频段}\times\text{步态阶段}
\]

例如：

- SMA-STN theta-alpha；
- M1-STN alpha；
- PMC-STN alpha；
- PMC-STN beta；
- S1-STN theta；
- SPL-STN相关耦合。

即使两个指标均被称为coherence，它们也不一定具有相同的功能意义。

此外，coherence只反映信号之间的统计同步关系，不能直接证明信息从皮层流向STN，或者从STN流向皮层。

**跨研究推断：FOG相关异常可能主要表现为网络通信和相位协调改变，而不一定表现为STN局部平均功率异常。**

### 4.6 神经活动与运动输出可能存在双向关系

STN活动与FOG之间的观察性关联，至少存在三种因果解释：

  <box background="rgba(59,130,246,0.07)" padding={2} radius="md" align="center">

  </box>
  <divider color="subtle"/>
  **模型B：STN作为网络异常的参与节点**

  <box background="rgba(139,92,246,0.08)" padding={2} radius="md" align="center">

现有研究没有充分区分它们。

尤其需要控制：

- 步态相位；
- 运动减速；
- 运动停止；
- 肌肉共同收缩；
- 感觉再传入；

因此，观察到STN信号与冻结同步变化，不能直接认定STN活动导致冻结。

<box border radius="lg" padding={3} gap={2}>
  **上游状态层**

  多巴胺状态、认知控制、注意负荷、空间知觉、疾病进展

  <icon name="arrow-down" color="secondary"/>

  **STN局部活动层**

  高beta平均功率、beta ERD、beta burst时间结构、alpha/theta/delta活动、神经复杂度

  <icon name="arrow-down" color="secondary"/>

  **网络协调层**

  皮层-STN coherence、PAC、跨频协调、STN空间分区及输出投射

  <icon name="arrow-down" color="secondary"/>

  **运动中介层**

  APA、步态启动、步态推进、双侧协调、下肢EMG时序

  <icon name="arrow-down" color="secondary"/>

  **下游运动网络**

  GPi、SNr、PPN、MLR及非多巴胺能系统

  <icon name="arrow-down" color="secondary"/>

| 分布式网络与运动控制 | H5–H10 | 冻结是否源于认知运动竞争、协调失败或下游输出异常？ | H5、H6、H10可处于不同因果层级 |

### 6.3 STN局部振荡机制

**H1：患者亚型依赖的STN局部高beta状态机制**

<badge color="info">假说</badge>

核心解释：部分FOG患者在特定疾病阶段或多巴胺耗竭状态下存在STN高beta同步或持续性高beta异常，干扰运动程序更新。

- **预测：** 控制疾病严重程度、药物状态、步速和步态相位后，特定FOG亚型仍表现出较高高beta同步。
- **区分性检验：** 在平均beta功率匹配的情况下，选择性抑制高beta同步仍应降低后续冻结风险。
- **反证条件：** 独立患者队列无法重复该关联；或者控制一般运动迟缓后关联消失；或者选择性降低高beta后冻结风险不变。
- **对应证据：** [PMID:24361601]、[PMID:39884164]。

H1的关键不是证明所有FOG患者都有高beta，而是验证是否存在高beta主导的患者亚型。

**H2：步态周期beta去同步化及相位调制失败机制**

核心解释：FOG可能源于STN不能在正常步态周期内适时调节beta活动。

- **预测：** 即使平均beta功率相同，未来发生冻结的步态周期仍应表现出异常ERD幅度、相位或恢复时间。
- **区分性检验：** 比较正常步态周期与随后发生冻结的步态周期，检验相位锁定beta指标是否独立预测冻结。
- **反证条件：** 充分控制步速、运动相位和感觉再传入后，beta动态指标不再预测冻结；选择性恢复正常相位调制也不改变冻结风险。
- **对应证据：** [DOI:10.21203/rs.3.rs-9617843/v1]、[PMID:41131028]。

H2与H1最重要的区别是：H1强调平均状态，H2强调时间和相位。

**H3：STN beta burst时间结构异常及运动门控机制**

核心解释：过长的beta burst、长burst比例增加或累计占据时间异常，可能维持当前运动状态，妨碍运动程序转换。

- **预测：** 冻结前长burst比例、累计持续时间或持续时间分布发生可重复变化。
- **区分性检验：** 控制平均beta功率后，burst时间结构仍应独立预测冻结。
- **反证条件：** 控制运动减速后，burst与冻结的关系消失；选择性缩短长burst不能降低冻结风险。
- **对应证据：** [PMID:30196050]、[PMID:31505548]、[DOI:10.21203/rs.3.rs-9617843/v1]。

H3与H2的主要区别是：H3强调burst分布，H2强调步态相位性调制。

**H4：STN局部theta/delta状态转换异常机制**

核心解释：STN局部低频活动可能参与认知处理、运动状态切换和感觉运动信息整合。

- **预测：** 真实冻结前后，STN局部theta/delta应出现可重复的事件锁定变化。
- **区分性检验：** 控制头皮EEG、步速、运动伪迹后，STN局部低频指标仍应提供独立预测信息。
- **反证条件：** 低频变化完全由运动伪迹或共同皮层输入解释，或者选择性改变STN局部低频活动不改变冻结风险。
- **对应证据：** [PMID:28890315]及皮层-STN耦合研究[PMID:31505548]。

需要特别避免把S1-STN theta coherence或PPNa theta相关活动当成STN局部theta功率。

### 6.4 分布式网络与运动控制机制

**H5：认知运动竞争及分布式皮层-STN网络信息传递失稳**

核心解释：双任务、窄门、转弯、障碍物和注意负荷造成认知控制与自动步行程序之间的竞争，STN去耦合只是更广泛网络异常的一部分。

- **预测：** 在步速和运动学匹配时，随机增加认知或空间负荷仍应改变皮层-STN连接并增加实际冻结风险。
- **区分性检验：** 固定STN刺激参数，独立操控认知负荷和视觉空间条件。
- **反证条件：** 控制认知负荷和空间条件后，网络指标不能预测冻结，且随机负荷操控不改变冻结发生率。
- **对应证据：** [PMID:23382821]、[PMID:31505548]、[PMID:41131028]。

**H6：APA、步态启动及双侧运动协调失配机制**

核心解释：姿势准备、内部运动驱动和实际步伐执行之间发生协调失败。

- **预测：** 冻结前存在可重复的APA异常、双侧步时协调变化或步态启动失配。
- **区分性检验：** 操控姿势准备时序，检验实际冻结风险是否随协调状态改变。
- **反证条件：** 真实冻结前不存在稳定的APA或双侧协调异常；选择性恢复协调不改变冻结。
- **对应证据：** [PMID:21370271]、[PMID:30196050]。

**H7：脑干运动网络及非多巴胺能系统参与的难治性FOG机制**

核心解释：晚期、左旋多巴抵抗性或STN刺激后残余FOG可能更多依赖SNr-PPN、MLR、胆碱能、去甲肾上腺素能及小脑网络。

- **预测：** 左旋多巴抵抗性FOG具有区别于OFF-only FOG的脑干或非多巴胺能网络特征。
- **区分性检验：** 在保持STN刺激参数不变时，独立调节PPN或SNr相关网络。
- **反证条件：** 控制疾病严重程度后，脑干和非多巴胺能指标不再解释冻结差异，且独立网络干预不改变实际冻结。
- **对应证据：** [PMID:24386308]、[PMID:24909584]、[PMID:23757762]。

**H8：STN空间分区及输出投射路由失衡机制**

核心解释：不同STN区域及其向GPi、SNr、皮层和脑干的输出具有不同功能。

- **预测：** 在总能量匹配时，改变刺激方向或接触点应产生可重复的FOG结局差异。
- **区分性检验：** 个体化VTA和连接组应能够在独立患者中预测治疗反应。
- **反证条件：** 前瞻性研究中，控制VTA后刺激位置不再预测FOG结局。
- **对应证据：** [PMID:37701817]、[PMID:39475137]。

**H9：皮层-STN及STN内部跨频耦合和相位路由失稳机制**

核心解释：FOG可能涉及不同频段之间，以及STN与SMA、M1、PMC、S1和SPL之间的相位协调异常。

- **预测：** 控制局部功率、步速及运动学后，特定PAC或coherence仍能独立预测冻结。
- **区分性检验：** 相位特异刺激与相位打乱刺激比较。
- **反证条件：** 耦合变化完全由局部功率、共同输入和步态周期解释；选择性改变相位关系不改变冻结。
- **对应证据：** [PMID:31505548]、[PMID:41131028]。

**H10：STN相关网络到下肢肌肉输出的时序失调机制**

核心解释：STN活动可能通过改变下肢拮抗肌共同收缩及交替激活时序参与FOG。

- **预测：** 冻结前STN变化应在时间上先于特定EMG异常。
- **区分性检验：** 同步记录双侧STN-LFP、下肢多肌群EMG及步态运动学。
- **反证条件：** 肌电异常总是先于STN变化，或控制共同运动指令后STN-EMG关系消失。
- **对应证据：** [PMID:35153698]、[PMID:41388789]。

### 6.5 神经复杂度的两个竞争解释

**H11：STN神经活动熵增加的病理性信息失序机制**

- **预测：** 熵增加应在冻结前出现，并在控制注意负荷、步速及平均功率后独立预测冻结风险。
- **反证条件：** 熵变化只在冻结后出现，或者控制任务复杂度后关联消失。
- **干预要求：** 尝试在功率匹配条件下改变神经时间结构，并观察实际冻结是否变化。

**H12：STN神经活动熵增加的代偿性信息重组机制**

- **预测：** 熵增加应更多出现在冻结后、恢复阶段或成功代偿的试次中，并与较短冻结持续时间或更快恢复相关。
- **反证条件：** 熵增加稳定出现在冻结前并预测更高冻结风险；或者较高熵与更差恢复持续相关。
- **干预要求：** 检验抑制复杂度增加是否损害恢复能力。

H11与H12是本报告中最明确的一对竞争性机制。

两者不能在结果出来后任意选择解释。必须预先注册相反的时间顺序和临床结局预测。

### 6.6 低频STN-DBS的三个竞争性治疗中介

这组三个假说直接关系到临床刺激参数优化。

**H13：低频STN-DBS通过PPNa及下行步行通路募集改善FOG**

- **预测：** 获益应与VTA和PPNa或相关下行通路的空间重叠程度相关。
- **反证条件：** 避免PPNa募集后仍有相同疗效，或PPNa活动变化与FOG改善没有时间关系。

**H14：低频STN-DBS通过改善运动不能间接减少FOG**

- **预测：** 步态启动、步速和运动推进改善应在时间上先于冻结减少，并解释部分疗效。
- **反证条件：** 一般运动功能不变时仍出现稳定FOG改善，或者一般运动明显改善而冻结完全不变。

**H15：低频STN-DBS通过局部振荡重组改善FOG**

- **预测：** 在匹配VTA及运动不能改善程度后，STN局部频谱或burst时间结构变化仍应独立预测冻结获益。
- **反证条件：** 低频刺激改善FOG时局部振荡没有相应变化，或严格能量匹配的神经反馈刺激不优于随机刺激。

这三个假说分别对应空间募集、运动学中介和STN局部神经活动中介。

**目前没有研究同时独立操控和验证三个中介，因此三者都应保留为假说。**

### 6.7 药物与刺激的交互机制

**H16：多巴胺能状态与STN刺激的非加和交互机制**

核心解释：不同患者的FOG可能由药物和刺激之间的非加和交互产生。

- **预测：** 同一患者的四种治疗状态应出现可重复的非加和交互项。
- **区分性检验：** 患者内随机2×2析因交叉设计。
- **反证条件：** 充分效能的随机析因研究显示药物和刺激效应符合简单加和模型。
- **对应证据：** [PMID:24396010]、[PMID:31275238]、[PMID:40504072]。

尤其需要区分四种临床表型：

| 临床表型 | 定义 |
|---|---|
| OFF-only FOG | 仅在药物OFF出现 |
| ON-only FOG | 仅在药物ON出现 |
| ON/OFF FOG | 两种状态下均出现 |
| 左旋多巴抵抗性FOG | 充分药物治疗后仍持续出现 |

不能将这些患者混合后只报告一个总体DBS疗效。

### 6.8 PMC-STN alpha耦合的两个相反解释

**H17：PMC-STN alpha耦合的代偿性网络重组机制**

- **预测：** 较高PMC-STN alpha coherence与较短冻结持续时间、更好的恢复能力相关。
- **反证条件：** 降低PMC-STN alpha耦合反而改善冻结，或者该指标与恢复完全无关。

**H18：PMC-STN alpha异常同步促进FOG的病理性耦合机制**

- **预测：** 异常PMC-STN alpha同步在冻结前或开始阶段出现，并与更长冻结持续时间相关。
- **反证条件：** 较高耦合稳定预测更短冻结，或降低耦合导致运动恶化。

H17与H18使用同一组观察现象，但临床预测方向相反。

在解决[PMID:41131028]内部结果报告不一致之前，不应对这两个假说给予过高权重。

### 6.9 TBS的两个时间尺度机制

**H19：TBS-DBS暂停期即时刺激遮蔽机制**

- **预测：** 暂停时间越长或暂停频率越高，暂停期间冻结风险越高。
- **反证条件：** 改变暂停长度不影响神经活动和冻结风险。

**H20：TBS-DBS长期网络可塑性及跨日适应机制**

- **预测：** 获益随长期治疗逐渐累积，并在停止刺激后的短期观察窗口中部分保留。
- **反证条件：** 长期TBS没有超过连续刺激的延迟获益，或者所有改善在刺激停止后立即消失。

H19和H20对应不同时间尺度，可能同时成立，并非必须二选一。

## 七、证据缺口与下一步研究：哪些实验最有价值？

现阶段的主要问题已经不是缺少候选机制，而是缺少能够区分候选机制的实验。

以下按照对机制识别和临床转化的价值排序。

### 7.1 优先级一：建立真实FOG事件的多模态同步记录

<badge color="success">最高优先级</badge>

目前最重要的缺口是缺乏同一患者、同一冻结事件中STN、皮层、肌肉及运动学的同步记录。

建议建立以下同步测量体系：

| 测量对象 | 主要指标 | 回答的问题 |
|---|---|---|
| 双侧STN-LFP | 功率、ERD、burst、复杂度 | 局部STN活动是否先于冻结？ |
| EEG/ECoG | SMA、M1、PMC、S1、SPL活动 | 皮层活动是否先于STN变化？ |
| 下肢EMG | 激活幅度、共同收缩、肌间同步 | 肌肉输出异常发生在STN变化之前还是之后？ |
| IMU | 步速、步幅、步频、转弯时间 | 冻结前是否存在运动学变化？ |
| 视频及三维运动学 | 冻结起始、持续时间、恢复 | 神经活动是否对应真实冻结事件？ |
| 足底压力或测力平台 | 步态相位、负重转移、姿势准备 | APA及双侧协调是否发生异常？ |

建议覆盖：

- 自然直线行走；
- 窄门行走；
- 180°转弯；
- 障碍物；
- 双任务；
- 步态启动。

每次事件应明确标记：

\[
\text{正常步态}
\rightarrow
\text{冻结前}
\rightarrow
\text{冻结开始}
\rightarrow
\text{冻结持续}
\rightarrow
\text{恢复}
\]

主要研究问题：

1. STN局部活动是否先于皮层连接变化？
2. STN活动是否先于肌肉共同收缩？
3. 哪些指标只在冻结后出现？
4. 不同诱发任务是否产生不同的神经活动模式？
5. 药物ON/OFF是否改变这些时间顺序？

这一研究可以同时检验H1–H10中的多个机制。

### 7.2 优先级二：统一beta及复杂度分析标准

建议在同一患者内同步比较以下指标。

| 类别 | 必须分别报告的指标 |
|---|---|
| Beta功率 | low beta、high beta、绝对功率、相对功率 |
| 运动相关调节 | beta ERD、步态相位调制、恢复时间 |
| Beta burst | 发生率、平均持续时间、长短burst比例、累计占据时间 |
| Burst时间结构 | inter-burst interval、持续时间分布 |
| 连接指标 | coherence、PLV、PAC、跨频耦合 |
| 复杂度 | Sample Entropy、Shannon entropy、Permutation entropy、Lempel-Ziv complexity |
| 非线性统计 | CV、MAD及其他明确算法定义的时间结构指标 |

必须统一：

- 频段边界；
- burst阈值；
- 归一化基线；
- 运动伪迹处理；
- 事件时间窗；
- 多重比较校正；
- 统计单位。

尤其需要直接回答：

**在同一患者、同一任务、同一药物和刺激条件下，平均beta功率、beta ERD、burst时间结构和复杂度是否提供相互独立的信息？**

这是区分H1、H2、H3、H9、H11和H12的基础。

这一实验可以直接检验H16，并为H1、H2、H3和H7提供患者分层信息。

### 7.4 优先级四：区分低频STN-DBS的三个治疗中介

目前低频刺激的三种解释尚未得到直接区分。

建议设计空间募集、运动学及局部神经活动相互匹配的刺激比较。

| 研究模块 | 关键操控 | 主要检验 |
|---|---|---|
| PPNa募集 | 不同方向、触点及VTA | H13 |
| 运动推进 | 独立改变步态启动或推进能力 | H14 |
| STN局部活动 | 选择性改变局部振荡及burst时间结构 | H15 |

需要同步测量：

- STN-LFP；
- PPN相关活动；
- VTA及组织募集范围；
- 步态启动；
- 步速及步幅；
- 实际冻结发生率和持续时间。

关键判定原则：

如果FOG改善完全由PPNa募集解释，那么STN局部振荡不应在控制空间募集后继续提供独立解释。

如果改善完全由运动推进改善解释，那么在运动推进不变时不应出现稳定的FOG特异性获益。

如果局部振荡变化仍能独立预测冻结改善，才有理由进一步支持H15。

### 7.5 优先级五：空间定位与投射连接组的前瞻性验证

建议建立统一的患者个体定位体系。

重点记录：

- STN背外侧、中心、后部及腹侧刺激；
- 双侧和单侧刺激；
- 方向性电极募集范围；
- 个体化VTA；
- 患者个体DTI连接组；
- STN-GPi、STN-SNr、STN-PPN及皮层-STN连接；
- 实际FOG变化。

采用随机、盲法、患者内交叉设计，并尽可能匹配TEED和VTA。

研究目的不是寻找一个事后统计得到的sweet spot，而是检验：

**能否根据患者个体的组织募集和连接特征，在刺激之前预测其FOG改善或恶化方向？**

如果无法在独立患者中重复预测，就不应继续将某个解剖位置描述为已经确立的抗冻结靶点。

### 7.6 优先级六：建立FOG解码模型的真正外部验证

现有STN-LFP分类器结果主要来自小样本和患者内个体化模型。

建议：

1. 按患者而不是按步态片段划分训练集和测试集。
2. 避免同一患者的冻结事件同时进入训练和测试。
3. 分别训练beta功率、beta burst、低频耦合和多模态模型。
4. 比较个体化训练与跨患者泛化。
5. 使用独立中心验证。
6. 在不同药物和刺激状态下验证。
7. 最终在自然生活场景中验证。

尤其需要区分：

- 冻结发生时的识别；
- 冻结发生前的预测；
- 冻结恢复的识别。

这三者不是同一个机器学习任务。

## 八、建议建立的长期证据管理与持续改进体系

本领域已经积累了大量研究，但文献数量增长并没有自动转化为机制确定性。

要让已有结果能够持续用于新问题，需要把文献管理升级为可追溯的证据管理。

### 8.1 建立分层证据数据库

建议将研究资料分为以下六个层级：

| 层级 | 唯一标识 | 应保存的信息 |
|---|---|---|
| 证据片段 | EID | 原文结果、统计值、实验条件 |
| 出版物 | PMID/DOI | 题名、作者、年份、版本 |
| 原始研究 | Study ID | 研究设计、实验方法 |
| 患者队列 | Cohort ID | 中心、招募时间、患者构成 |
| 患者与事件 | Patient/Event ID | 患者数、冻结次数、试次数 |
| 综合结论 | Claim ID | 结论、证据强度、支持与反对关系 |

尤其需要建立：

**Publication ↔ Study ↔ Cohort ↔ Patient ↔ Event ↔ Evidence ↔ Claim**

之间的关联。

例如，同一研究的预印本和正式版应该指向同一个Study ID；同一患者在不同文章中的重复分析应该指向同一个Cohort ID。

目前Cohort ID尚未得到充分确认，这应该是长期证据管理的首要改进任务。

### 8.3 建立Claim-Evidence双向更新机制

每个重要结论都应该能够回答：

1. 有哪些原始研究支持？
2. 有哪些研究反对？
3. 这些研究是否来自独立队列？
4. 是否存在预印本与正式版重复？
5. 是否存在研究条件不同导致的表面冲突？
6. 哪个新发现足以改变当前结论？

### 8.5 如何判断知识系统是否真的改善？

不能以新增文献数量或新增证据条目数量作为主要指标。

|---|---|
| 文献可追溯性 | 重要结论能否定位到原始研究及具体结果 |
| 队列独立性 | 是否识别并排除重复患者队列 |

| 纠错有效性 | 发现错误后，旧结论是否得到真实修正 |

**真正的改进标准是：新证据进入后，系统能够更准确地区分已经验证的结论、仍有争议的结论及尚未验证的机制。**

### 最值得优先回答的三个科学问题

**问题一：STN究竟是FOG的上游驱动因素，还是分布式网络异常中的参与节点？**

需要通过同步多模态记录和选择性干预确定时间顺序与因果作用。

**问题二：FOG相关STN异常究竟是平均高beta、步态相位调制失败，还是beta burst时间结构异常？**

需要在相同患者、相同任务中同时测量这些指标，并进行独立操控。

**问题三：低频STN-DBS的抗冻结效果究竟通过局部STN活动、邻近PPNa募集，还是一般运动推进改善实现？**

需要采用空间募集匹配、能量匹配及正式中介分析。

### 最终判断

现有研究已经从单纯的STN beta功率研究，发展到涉及beta burst、神经复杂度、皮层-STN耦合、双侧协调、肌肉输出和脑干网络的多层次研究。

但目前证据最薄弱的部分，恰恰是从神经活动相关性到因果机制的跨越。

下一阶段最有价值的工作，不是继续寻找一个能够解释所有FOG的单一频段，而是通过同一患者内的时间分辨记录、选择性干预和独立队列验证，明确不同FOG表型究竟由哪些神经动态过程主导。

**研究方向上的核心转变应当是：从寻找统一的STN异常信号，转向识别不同患者亚型中可干预、可预测、具有明确因果时间顺序的STN相关网络机制。**

这既是目前证据能够支持的最稳健结论，也是最值得投入后续功能神经外科研究资源的方向。
