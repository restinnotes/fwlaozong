# 丘脑底核神经活动与帕金森病冻结步态的关系：临床证据、电生理冲突与竞争性机制模型

**研究领域：** 功能神经外科、脑深部电刺激（DBS）、丘脑底核（STN）、帕金森病（PD）及冻结步态（freezing of gait，FOG）。

**研究类型：** 基于结构化文献证据的批判性综述与机制假说综合。

**资料范围：** 仅使用本次提供的结构化结论、假说及 `evidence_table.txt` 中的证据。不引入外部文献或额外实验数据。对于预印本、综述转述、小样本研究和未直接观察到冻结事件的研究，分别标明其证据性质。

---

## 一、核心结论与研究定位

### 1.1 总体判断

目前最合理的结论不是“STN beta 活动升高导致FOG”，也不是“STN活动只是FOG的伴随现象”，而是：

**STN是FOG相关运动控制网络中的重要动态节点，其神经活动与冻结易感性、步态启动、运动推进、实际冻结及冻结恢复均存在关联，但这些关联受到行为阶段、频段、解剖位置、患者表型和外部网络状态的共同影响。**

现有研究支持STN参与FOG相关神经网络状态转换，但尚未证明某一种STN自发神经活动模式是FOG发生的必要或充分条件。

这一判断需要建立在以下五个层次上。

| 证据层次 | 当前结论 | 证据状态 |
|---|---|---|
| 临床干预 | STN-DBS可以改善部分患者的FOG，也可能使部分患者恶化 | 直接证据；跨研究推断 |
| 事件级电生理 | 实际FOG期间及其前后，STN-LFP存在可测量的动态变化 | 直接证据 |
| 神经活动特征 | beta功率、beta burst、theta、alpha及复杂度指标均可能携带FOG相关信息，但方向并不统一 | 跨研究推断 |
| 网络机制 | STN与SMA、运动皮层、前额叶、小脑及脑干步行网络共同参与FOG | 跨研究推断 |
| 因果机制 | beta状态转换失败、网络过载、区域功能分工、PPN/MLR募集等均可能解释部分现象 | 假说，尚未充分验证 |

### 1.2 最值得强调的五项发现

**第一，STN-DBS对FOG具有真实的临床调节作用，但不能据此推断STN内源性神经活动的病因作用。**

刺激可以改善或恶化FOG，说明刺激所募集的神经组织及其连接网络能够影响冻结表现。但DBS同时作用于局部神经元、传入传出纤维和邻近结构，不能将临床疗效直接归因于STN beta 功率或某种特定振荡模式。

**第二，STN beta功率不存在适用于所有患者和行为阶段的统一方向关系。**

Freezers可以表现为较高的静息或步行beta活动，也可以在实际冻结期间出现beta功率下降。beta burst持续时间、运动相关去同步化和平均功率之间也可能出现不同结果。

**第三，时间结构和行为阶段可能比平均频谱功率更重要。**

beta burst持续时间、burst分布、低beta运动相关去同步化（ERD）及皮层-STN耦合的变化，可能提供平均beta功率不能提供的信息。

**第四，STN具有区域和通路特异性。**

posterior STN和central STN可能分别关联步态推进、节律和平衡等不同运动维度。刺激接触点与结构连接网络可能比单纯的STN解剖定位更能解释临床差异。

**第五，FOG不能被简化为STN局部振荡异常。**

多巴胺反应性、认知负荷、焦虑、姿势准备、双侧步态协调及非多巴胺能网络都可能改变STN活动与冻结之间的关系。

这些结论共同指向一个研究转向：从寻找单一FOG神经标志物，转向研究STN及其连接网络在不同运动阶段中的动态组织和状态转换。

## 二、证据全景：从临床干预到神经活动

### 2.1 STN-DBS对FOG的临床作用：有效，但并非普遍有效

这是目前证据数量较多、临床意义最明确的研究方向。

**（1）支持STN-DBS改善FOG的证据**

Ferraye等对123名患者开展术前与术后比较，发现STN刺激能够在多数术前具有左旋多巴反应性FOG的患者中重现左旋多巴的改善效果。但11名术前无FOG的患者术后首次出现FOG或无法完成步行测试。[PMID:18413568]

EARLYSTIM试验的二次分析纳入251名患者。24个月时，STN-DBS组依据UPDRS-II第14项判断的FOG比例从52%下降至34%，而最佳药物治疗组没有出现相同变化。[PMID:31755599]

Gavriliuc等对124名FOG患者开展观察者盲法评估，发现STN-DBS和左旋多巴均能改善不同诱发情境下的FOG，联合治疗的改善更明显。转弯是该研究中最敏感的冻结诱发情境。[PMID:33027712]

2023年的回顾性研究纳入76名患者：

- 42人FOG改善；
- 22人变化较小；
- 12人恶化；
- 18人FOG完全消失。

整体FOG-Q从16.89下降至10.05，但个体反应差异明显。[PMID:37701817]

Temiz等的19人队列也发现，术后FOG-Q平均改善36%，但5/19患者反而恶化。[PMID:36242900]

这些结果支持STN-DBS具有抗冻结临床作用，同时也说明平均治疗效应不能代表患者个体反应。

**（2）与阳性结果相冲突的证据**

Guo等2025年网络Meta分析纳入25项随机对照试验。在FOG-Q分析中，涉及的11种DBS模式均未获得统计学显著改善，包括常规STN-DBS、60 Hz STN-DBS及80 Hz STN-DBS。

该分析存在：

- FOG-Q网络异质性I²=88.3%；
- 显著的研究间不一致；
- Egger检验提示潜在发表偏倚或小样本效应。

因此，不能将其解释为STN-DBS对FOG完全无效，但它确实削弱了“STN-DBS能够稳定改善所有患者FOG”的结论。[PMID:41659700]

另一项2026年更新Meta分析纳入31项研究、905名患者，整体FOG-Q改善，尤其在Med-Off/Stim-Off与Med-Off/Stim-On比较中较为明显。

但该分析涉及不同DBS靶点，不能将总体效应全部归因于STN。[PMID:42098512]

**（3）临床异质性并非单纯的统计噪声**

Barbosa等2025年研究进一步显示，药物与刺激对FOG可能产生相反的个体反应：

- 3/17患者：左旋多巴改善FOG，但STN刺激使FOG恶化；
- 5/17患者：左旋多巴加重FOG，但STN刺激改善FOG。

这意味着部分患者的FOG可能具有不同于其他帕金森运动症状的治疗反应特征。[PMID:40504072]

此外，术后步态恶化也不能全部等同于FOG恶化。系统综述报告的术后步态或平衡恶化病例中，冻结和跌倒较常见，但综合结局不能直接转换为FOG发生率。[PMID:40092840]

<text color="secondary" size="xs">证据解释：上述研究属于临床干预、观察性队列和Meta分析证据，不是STN内源性神经活动的直接测量。</text>

### 2.2 刺激频率：60 Hz可能有益，但不存在普遍适用的最佳频率

低频刺激（LFS）是STN-DBS治疗FOG研究中最重要的交叉方向之一。

Xie等总结的一项随机、双盲、前瞻性交叉研究纳入13名患者，所有患者均在常规高频刺激下出现FOG。

研究比较：

- DBS关闭；
- 130 Hz常规电压；
- 130 Hz高电压；
- 60 Hz等效总电能输送量（TEED）；
- 60 Hz高电压等效能量条件。

60 Hz条件在Stand-Walk-Sit测试中的步态表现和冻结发作次数优于130 Hz条件。60 Hz高电压条件在8个月后仍有85%的患者保持步态获益。[PMID:28529730]

另一项7人随机交叉研究也报告60 Hz低频刺激可以改善持续性FOG。[PMID:25540305]

但低频刺激并非普遍有效：

- 一项17人研究中，60 Hz与130 Hz之间的实际FOG发作次数没有显著差异，尽管轴性症状评分有所改善。[DOI:10.21203/rs.3.rs-4058858/v1]
- 一项16人随机交叉可行性试验发现，60 Hz改善站立平衡及步态启动运动阶段的平衡，但没有改善步态启动的姿势阶段，也没有直接证明FOG改善。[PMID:42240331]
- 网络Meta分析没有发现60 Hz STN-DBS能够显著改善FOG-Q。[PMID:41659700]

因此，较为合理的结论是：

**低频刺激可能对某些在常规高频刺激下出现冻结或轴性症状恶化的患者具有特殊价值，但目前不能证明其普遍优于130–150 Hz常规刺激。**

尤其需要注意，等效TEED不代表相同的神经组织募集。频率变化可能同时改变刺激电流扩散、神经纤维募集和局部神经动力学。

### 2.3 解剖位置与结构连接：从STN坐标转向刺激网络

STN内部不同位置以及STN周围结构的刺激，可能产生不同甚至相反的步态效应。

目前有三类较重要的证据。

**第一类：刺激位置与FOG改善或恶化相关。**

Fleury等研究了17名刺激后步态恶化患者，其中12人完成完整评估。导致恶化的接触点主要位于STN背侧和前方的前部未定带及Forel区H2。

这说明部分刺激相关FOG恶化可能来自STN邻近结构募集，而非STN内部神经活动本身。[PMID:26887333]

Schott等在66名患者中发现，FOG改善者的电极位置略偏内侧，双侧电极内外侧位置不对称性较小。[PMID:35418844]

**第二类：STN刺激效果与结构连接网络相关。**

Strelow等研究47名患者，发现与FOG改善相关的刺激体积连接于运动区、前额叶、苍白球及经过PPN和黑质的纤维；刺激豆状束与FOG恶化相关。[PMID:35431262]

Fan等研究76名患者，发现刺激STN-SMA/pre-SMA连接纤维与FOG改善相关，而刺激mPFC和vlPFC相关纤维与较差的FOG结果相关。部分改善相关纤维继续延伸至MLR/PPN。[PMID:37701817]

**第三类：定向刺激提示区域功能差异。**

10名晚期FOG患者的随机双盲交叉研究发现，中心STN定向刺激在降低实际FOG概率方面优于后部STN定向刺激，但中心刺激与常规ring模式之间没有显著差异。[PMID:39475137]

这些结果支持通路特异性刺激网络模型，但还不足以证明某一STN区域具有唯一或普遍最佳的治疗价值。

## 三、STN神经活动与FOG的直接电生理证据

这是本研究问题最核心的部分。需要特别区分：

1. FOG易感患者与非易感患者之间的差异；
2. 正常步态与冻结前状态之间的差异；
3. 实际冻结期间的神经活动；
4. 冻结恢复阶段的神经活动。

这四种状态不能合并成一个笼统的“FOG相关STN活动”。

### 3.1 STN beta功率：最重要的冲突

现有研究报告了三种不同的结果。

<badge color="success">方向一：beta升高</badge>

Toledo等研究22名PD患者，其中14名有FOG、8名无FOG。

发现FOG患者的STN高beta功率显著高于非FOG患者（F=11.6，p=0.002）。左旋多巴给药后，高beta活动下降，同时FOG受到抑制。[PMID:24361601]

Liu等同步记录8名FOG患者的STN-LFP、皮层电活动及步态。患者在实际FOG期间的STN beta功率显著高于非冻结步行期间。[PMID:35310098]

Thenaisie等在4名患者中观察到，转弯冻结期间STN低beta功率高于正常步行或站立状态。[PMID:36070366]

另有术中虚拟现实研究报告，实际冻结期间STN神经元放电频率以及beta、theta活动升高。该结果来自8名患者，且属于不同于自然步行的实验范式。[PMID:40072634]

这些研究共同支持：部分FOG患者在特定任务和冻结阶段存在STN beta活动增强。

<badge color="warning">方向二：beta降低</badge>

Syrkin-Nikolau等研究14名患者，其中8名Freezers、6名Non-Freezers。

研究发现：

- Freezers在原地踏步但未冻结时，STN beta功率低于Non-Freezers；
- Freezers在实际FOG期间，beta功率又低于其正常前向行走期间。

第二个结果的统计效应为F(1,51)=14.45，p小于0.001。[PMID:28890315]

这里存在一个重要的实验条件问题：FOG主要通过转弯、障碍通行等复杂任务诱发，而正常步行条件并不具有完全相同的任务负荷。

因此，beta下降可能与冻结状态、复杂任务或运动方式变化共同相关，不能直接解释为冻结特异性抑制。

<badge color="info">方向三：平均功率方向不一致，但运动调制异常</badge>

2026年的转弯研究提供了一个不同的观察角度。

Klocke等研究13名患者，其中11名在实验中出现转弯冻结，共记录122次FoG-Turn。

在Med-Off/Stim-Off条件下：

- 正常转弯和正常行走期间，STN低beta出现明显ERD；
- 实际冻结转弯期间，低beta ERD缺失；
- alpha和高beta的去同步化仍然保留。

低beta ERD缺失的统计结果为p=0.0002。

这提示实际冻结期间的问题可能不是简单的beta绝对功率升高，而是正常运动所需的低beta去同步化不能充分发生。

该研究为预印本，样本量仍较小。[DOI:10.21203/rs.3.rs-9617843/v1]

**综合判断：**

目前不能确立“FOG期间beta升高”或“FOG期间beta降低”为普遍规律。

更合理的解释是，beta功率与FOG的关系受到以下因素影响：

- 低beta与高beta的不同作用；
- 静息功率与运动期间功率；
- 绝对功率与相对于静息基线的ERD；
- 正常行走、原地踏步及转弯任务；
- 冻结前、冻结中和恢复阶段；
- 患者是否属于特定FOG亚型。

因此，跨研究比较时必须首先确认测量对象是否相同。

### 3.2 Beta burst：时间结构可能比平均功率更接近病理过程

Anidi等研究认为，FOG患者的STN beta burst持续时间较长。

在实际发生冻结的5名Freezers中，冻结期间的beta burst持续时间显著长于同一任务中的非冻结阶段（F(1,815)=13.114，p小于0.001）。[PMID:30196050]

这一结果与平均beta功率并不完全等价。

可以将beta活动拆分为几个不同维度：

| 指标 | 反映的内容 | 需要回答的问题 |
|---|---|---|
| Beta power | 某频段振荡能量 | beta活动总体强度是否改变？ |
| Burst duration | 单次振荡爆发持续时间 | 长时间同步活动是否增加？ |
| Burst occupancy | 超阈值活动占据时间比例 | 病理活动是否占据更多时间？ |
| Burst distribution | 不同持续时间burst的分布 | 短burst与长burst之间是否重新分配？ |
| Beta ERD | 运动期间相对基线的去同步化 | 正常运动调制是否发生失败？ |
| Burst timing entropy | burst发生时间分布的复杂性 | 活动时间组织是否变得更加可预测？ |

2026年的转弯研究尤其值得关注。

实际FoG-Turn期间：

- 平均burst持续时间相对于站立基线没有显著变化；
- 但与正常步行相比，短burst比例下降；
- 长burst比例增加。

因此，平均持续时间不变并不代表burst组织没有发生变化。

这项研究报告，FoG-Turn与Regular Walking之间的burst持续时间分布交互作用显著，校正后p=0.003。[DOI:10.21203/rs.3.rs-9617843/v1]

同一研究还发现，冻结前转弯阶段的100–200 ms短burst比例可能下降，但Pre-FoG-Turn与Pre-Regular-Turn之间的直接比较仍不充分。

这意味着需要区分：

- 冻结易感性；
- 冻结前的状态转换；
- 实际冻结期间的burst重组。

不能将这三个过程统一描述为“beta burst延长”。

### 3.3 Theta与低beta：可能反映不同的运动控制维度

STN theta和低beta活动与步态启动、节律、平衡及实际冻结均存在关联，但不同研究的变化方向并不一致。

Collomb-Clerc等2025年的研究纳入38名PD患者，其中：

- FOG-OBS组12人；
- FOG-NOBS组26人；
- 分析了1229个有效步态启动试次；
- 记录267个STN双极位点。

重要的是，该研究分析的是步态启动时尚未发生实际冻结的试次。

研究发现，FOG阳性试次中：

- posterior STN high-beta与pace之间出现更强的负向关联；
- posterior STN high-beta和theta与rhythm之间出现不同于非冻结试次的关联；
- central STN high-beta与balance之间出现更强的负向关联；
- posterior STN gamma与balance之间出现正向关联。

FOG阳性试次的冻结通常发生于步态启动后数步，因此这些结果属于冻结前兆或易感状态证据，不是冻结期间的直接记录。[PMID:40709562]

另一方面，2026年转弯研究发现：

- 正常转弯的theta峰值功率高于正常行走；
- 正常转弯准备阶段也存在theta峰值增强；
- 实际FoG-Turn期间，theta峰值功率低于正常行走；
- Pre-FoG-Turn的theta峰值没有显著改变。

这一结果提示，正常转弯可能需要theta相关的运动准备或认知参与，而实际冻结时这种活动没有正常出现。[DOI:10.21203/rs.3.rs-9617843/v1]

与此不同，术中VR研究曾观察到冻结开始及冻结期间theta活动升高。[PMID:40072634]

因此，theta也不能被简单定义为FOG的升高或降低标志。

一个值得检验的解释是：theta在不同研究中可能反映运动准备、认知参与、节律控制和实际冻结期间不同的网络状态。

### 3.4 STN-皮层耦合：冻结可能涉及网络状态转换失败

Pozzi等同步记录7名患者的64通道EEG和双侧STN-LFP，其中5名FOG患者共发生14次冻结。

研究比较了：

- 有效行走；
- 冻结前1.5秒；
- 冻结开始；
- 冻结结束；
- 冻结后恢复行走。

发现SMA、M1、顶叶皮层与STN之间的4–13 Hz theta-alpha耦合，在冻结发生前已经下降，并在冻结期间持续降低；恢复有效行走后，这种耦合重新出现。[PMID:31505548]

这是目前较有价值的事件级网络证据，因为它包含了冻结前、冻结中和恢复期。

不过，研究只有7名患者，且全部冻结均发生于接近门洞时，实验条件为Med-Off、DBS-Off。因此不能直接推广到所有类型的FOG。

2025年的转弯研究进一步提供了PMC-STN和M1-STN alpha耦合的证据。

Zhang等研究19名患者，记录87次冻结转弯和52次正常转弯，发现：

| 脑区连接 | 行为阶段 | 观察结果 |
|---|---|---|
| PMC-STN alpha | 正常转弯准备期 | 相对于直线行走增强，p=0.0045 |
| PMC-STN alpha | 冻结转弯开始期 | 相对于直线行走增强，p=0.048 |
| M1-STN alpha | 冻结转弯开始期 | 相对于直线行走下降，p=0.043 |
| PMC-STN beta | 不同转弯阶段 | 未发现显著相位差异 |
| M1-STN beta | 不同转弯阶段 | 未发现显著相位差异 |

值得注意的是，冻结转弯的PMC-STN alpha增强出现在TurnStart，而正常转弯的增强出现在TurnPre。

但两种状态分别相对于Walk进行比较，不能仅凭这两个显著性结果证明两者之间存在统计学显著的时相迁移。

该研究还报告PMC-STN alpha指标与冻结持续时间的关联，但正文与图注对关联方向的描述存在不一致，必须保留这一不确定性。[PMID:41131028]

### 3.5 神经活动复杂度：不能把不同熵指标合并成一个概念

Syrkin-Nikolau等发现：

- Freezers在无冻结原地踏步期间，beta Sample Entropy高于Non-Freezers；
- 实际FOG期间，alpha Sample Entropy高于无冻结行走期间。

[PMID:28890315]

2026年Beaudoin等对4名患者的既有STN-LFP数据进行二次分析，共观察176次FOG发作。

发现冻结前转弯阶段的STN beta burst timing Shannon entropy低于稳定转弯阶段，在low-beta和high-beta两个频段均观察到这一结果。[DOI:10.64898/2026.08.13.744293]

这两个结果表面上存在方向冲突，但实际上测量对象不同：

- Sample Entropy：信号时间序列的复杂度或可预测性；
- Burst timing Shannon entropy：burst发生时间分布的熵；
- Lempel-Ziv complexity：序列模式复杂程度。

它们不能直接相互替代。

目前没有充分证据支持“FOG期间STN神经复杂度统一升高”或“统一降低”。

更有价值的方向是研究：**在正常行走向冻结转换的过程中，STN活动的时间可预测性和频率组织是否发生特定改变。**

### 3.6 STN-LFP能否用于FOG检测？

目前已经出现初步的机器学习证据。

Liu等利用STN-LFP多频段功率特征区分FOG与非FOG片段，报告：

- 分类准确率77%；
- AUC=0.75；
- 置换检验p小于0.01。

[PMID:35310098]

2026年的VR研究纳入5名患者、30次FOG事件，采用STN-LFP多通道和多频段特征。

经过transfer learning后：

- weighted F1由0.57提高至0.67；
- macro F1由0.51提高至0.62；
- 正文报告检出30次事件中的24次。

[PMID:42239677]

这些结果说明STN-LFP具有一定的冻结状态解码信息。

但是，必须区分三种不同任务：

1. 识别已经发生的FOG；
2. 识别即将发生FOG的易感状态；
3. 在冻结发生前足够长的时间提前预测FOG。

目前第一类任务已有初步证据，第二类任务开始出现探索性结果，第三类任务尚未得到充分验证。

而且小样本模型可能存在患者内数据泄漏、试次依赖和过拟合，尚不能视为临床可用的FOG生物标志物。

## 四、研究结果冲突的来源：为什么同一个STN会得到不同结论？

上述结果并不必然互相否定。更重要的问题是，它们究竟在测量同一种神经现象，还是不同层级的运动控制过程？

我认为至少有七个需要明确控制的冲突来源。

### 4.1 行为阶段不同：最重要的潜在混杂因素

将FOG作为单一状态进行研究，会掩盖其内部时间结构。

建议将行为状态明确划分为：

| 状态 | 主要生理问题 | 不能与什么混淆 |
|---|---|---|
| 静息 | 基础振荡状态 | 运动相关活动 |
| 步态启动前 | 运动准备、APA | 实际冻结 |
| GI启动后 | 推进与节律形成 | 正常持续行走 |
| 冻结前 | 状态转换失败 | 冻结发生时 |
| 实际冻结 | 运动输出中断或异常 | 运动减速 |
| 冻结恢复 | 网络重新组织及运动恢复 | 冻结前状态 |

例如，2025年的STN区域研究分析的是随后可能发生FOG的步态启动试次，而2026年的转弯研究直接分析了FoG-Turn。

二者不应作为相同类型的事件级证据进行合并。

### 4.2 任务范式不同

现有研究包括：

- 原地踏步；
- 前向行走；
- 转弯；
- 门洞通行；
- 障碍物行走；
- 步态启动；
- 虚拟现实行走；
- 骑行。

这些任务需要不同程度的推进、平衡、姿势调整、视觉处理和认知参与。

例如，Syrkin-Nikolau研究中的TBC与普通前向行走并非完全相同的任务，因此观察到的beta下降可能同时受到运动模式和任务复杂度影响。[PMID:28890315]

### 4.3 频段定义不一致

不同研究采用的beta范围包括：

- 12–22 Hz；
- 13–20 Hz；
- 13–30 Hz；
- 20–30 Hz；
- 21–35 Hz。

因此，研究中所谓的beta变化可能并非同一个神经频率成分。

尤其需要区分low-beta与high-beta，不能将整体beta功率直接解释为统一的病理活动。

### 4.4 患者表型不同

至少应区分：

- 左旋多巴反应性FOG；
- 左旋多巴抵抗性FOG；
- OFF-FOG；
- ON-FOG；
- 常规HFS下诱发或恶化的FOG；
- 疾病进展相关的轴性FOG；
- 具有明显认知或焦虑诱发特征的FOG。

FOG本身也存在不同的临床情境亚型。[PMID:30153383]

### 4.5 药物与刺激条件不同

Med-Off/Stim-Off、Med-Off/Stim-On、Med-On/Stim-Off和Med-On/Stim-On不能混为一谈。

特别是药物与刺激可能存在非加和交互作用。

Mei等单病例研究报告，患者术前只有OFF-FOG，术后在左旋多巴与130 Hz STN刺激联合使用时出现严重ON-FOG。[PMID:31275238]

该结果不能代表普遍现象，但提示必须在实验设计中独立操控药物和刺激状态。

### 4.6 神经测量指标不同

平均功率、ERD、burst持续时间、burst分布、熵、PAC及coherence属于不同的统计对象。

例如：

- beta功率下降不意味着burst持续时间一定缩短；
- 平均burst持续时间不变不意味着burst分布没有改变；
- coherence增强不意味着信息传递方向明确；
- entropy升高不一定意味着病理活动增强。

如果不同研究将这些指标统称为“STN beta异常”，就会产生人为的研究冲突。

### 4.7 统计与研究质量限制

现有研究还存在：

- 独立患者数量少；
- 单病例和小样本重复测量；
- 事件数被误当成独立样本数的风险；
- 运动伪迹；
- 不同触点之间的空间信息丢失；
- 多重比较；
- 预印本尚未同行评审；
- 预测模型缺乏外部验证；
- 综述与原始研究证据混合；
- 量表结局与实际冻结事件不一致。

因此，研究结果的冲突既有真实生理异质性，也有方法学异质性。

不能把所有阴性结果归咎于统计效能不足，也不能把所有阳性结果都解释为发现了FOG特异性机制。

## 五、跨环路证据：STN不是FOG的唯一病理起点

如果仅研究STN局部LFP，可能无法解释以下现象：

- 同样的STN beta变化，在不同患者中产生不同的临床表现；
- 部分患者FOG改善时，STN局部beta并未表现出相应的正常化；
- 转弯、双任务和情绪负荷对冻结的诱发作用明显不同；
- 刺激邻近结构或不同白质通路可能产生相反的步态效应。

现有交叉研究主要涉及四类网络。

### 5.1 基底节-SMA-MLR步行网络

Fling等发现，FOG患者表现出SMA与双侧MLR及小脑步行区之间的功能连接增强，且SMA-MLR连接强度与FOG严重程度相关。[PMID:24937008]

Shine等发现，FOG与认知控制网络和基底节网络之间的功能脱耦有关。[PMID:24142148]

Fan等的STN刺激连接组研究进一步提示，刺激SMA/pre-SMA相关通路可能与FOG改善有关，而前额叶相关通路的募集可能产生相反效果。[PMID:37701817]

由此形成一个重要的解释：

STN可能通过基底节-SMA-MLR通路参与内部运动提示、步态启动和运动推进，而前额叶认知控制输入可能影响该运动网络的稳定性。

不过，SMA-MLR连接增强也可能是代偿性重组，并不能直接认定为FOG的病因。

### 5.2 STN-小脑及感觉运动网络

Lench等研究55名患者，其中38名FOG患者分为：

- 多巴胺反应性FOG：22人；
- 多巴胺不反应性FOG：16人。

研究发现两类患者的STN连接模式存在差异，涉及：

- STN-小脑；
- STN-枕叶；
- STN-中央后回。

其中，STN-小脑连接与多巴胺反应性有关，STN-中央后回连接则在多巴胺不反应性FOG患者中表现出不同特征。[PMID:38101024]

这为FOG的网络分型提供了证据，但研究采用药物ON状态下的静息态fMRI，没有同步记录STN电生理，也没有实际冻结诱发任务。

因此，它不能证明这些连接差异就是相应FOG亚型的电生理机制。

### 5.3 非多巴胺能系统

Hvingelby等对14名FOG患者开展胆碱能PET研究，发现胆碱能空间协方差模式与药物ON状态下的FOG及步态指标有关。[PMID:40512756]

这一方向很重要，因为它提示：

部分FOG可能不再主要由STN相关多巴胺能运动环路决定。

随着疾病进展，非多巴胺能系统的变化可能影响患者对左旋多巴和STN-DBS的反应。

但目前尚未建立胆碱能功能变化与特定STN-LFP模式之间的对应关系。

### 5.4 STN-肌肉与双侧步态协调网络

双侧STN-LFP研究发现，左右STN平均beta burst持续时间差异与双腿stride time差异存在较强正相关（r=0.853，p=0.002）。[PMID:30196050]

Simpson等2026年进一步同步记录14名患者的双侧STN-LFP及腓肠肌、腓骨长肌EMG。

研究发现STN beta burst与运动启动阶段的下肢肌肉beta活动存在时间关联，左旋多巴还能够改变肌间beta同步性。[PMID:41388789]

Klocke等的研究则报告冻结前和冻结期间存在拮抗肌共同激活及异常肌肉时序控制的相关证据。[PMID:39470410]

这些结果支持一个值得研究的方向：

FOG可能不仅是中枢运动驱动不足，也可能是STN活动、姿势准备、肌肉激活和双侧运动协调之间的时间耦合失败。

但上述双侧burst和肌肉同步研究并不都直接观察了真实FOG，因此不能将步态不对称或肌间协调变化直接等同于冻结机制。

## 六、竞争性机制假说及其区分性预测

以下保留所提供知识库中的H1–H13编号，以便后续研究结果能够直接关联到原有假说。

我将这些假说组织成六组竞争关系。需要强调，它们并不全部互斥：例如，FOG亚型差异（H11）可以同时影响beta动态（H1）、网络负荷（H6）和肌肉协调（H8）。

### 6.1 H1与H2：STN beta是致病驱动，还是运动状态伴随标志？

<text weight="semibold" color="default">H1：STN运动相关beta状态转换失败假说</text>

核心观点：

FOG的部分病理过程不是持续性beta平均功率升高，而是正常步态所需的相位特异性beta去同步化和burst时间结构调节失败。

例如，冻结前可能无法充分降低低beta同步，或出现长burst比例增加，导致步态推进、节律和自动化维持受损。

支持证据：

- FOG期间beta burst持续时间延长。[PMID:30196050]
- 实际冻结转弯期间低beta ERD缺失。[DOI:10.21203/rs.3.rs-9617843/v1]
- 冻结前STN beta burst时间分布熵下降。[DOI:10.64898/2026.08.13.744293]
- 部分刺激研究发现beta burst缩短与步态改善同时发生。[PMID:30196050]

**区分性预测**

1. 同一患者、相同任务和相同步态相位下，随后发生FOG的试次应比正常试次表现出更明显的低beta ERD缺失或长burst比例增加。
2. 异常应在冻结发生之前出现。
3. 控制步速、步幅、转弯角速度、药物状态和姿势变化后，异常仍应具有独立预测价值。
4. 针对异常步态相位恢复beta动态，应比不考虑行为阶段的连续刺激更有效地减少客观冻结事件。

**反证条件**

- 充分控制运动学因素后，冻结前beta异常不再具有预测能力。
- 选择性恢复beta ERD或改变burst分布后，实际冻结发生率没有改变。
- FOG显著改善时，beta异常持续存在且不具有任何中介作用。

<divider color="subtle"/>

<text weight="semibold" color="default">H2：STN beta为运动状态伴随标志的共同原因假说</text>

核心观点：

beta变化主要反映步态减速、运动计划、姿势调整、认知负荷或整体网络状态，而非FOG的必要致病因素。

FOG和beta异常可能来自共同的上游网络障碍，也可能是冻结相关运动状态改变导致STN活动继发变化。

**区分性预测**

1. 控制步速、步幅、转弯角速度、APA和认知负荷后，beta与FOG的独立关联显著减弱。
2. 相似beta异常也会出现在没有实际冻结的复杂运动或减速状态中。
3. 选择性改变beta功率或burst持续时间，不一定改变客观冻结发生率。
4. 某些治疗可以减少FOG，而beta异常仍然存在。

**反证条件**

- 在严格匹配运动学及认知负荷后，beta仍能稳定提前预测FOG。
- 选择性操纵STN beta能够剂量依赖地改变冻结风险。
- beta变化能够解释刺激治疗效果中显著且可重复的中介比例。

**H1与H2的关键分界：**

不是观察beta是否变化，而是判断beta异常是否在控制运动状态后仍然存在，以及选择性改变beta是否能够改变FOG。

---

### 6.2 H3：Posterior-central STN区域功能分工假说

核心观点：

posterior sensorimotor STN和central associative STN可能参与不同的步态控制维度。

- Posterior STN：主要关联步态推进和节律；
- Central STN：可能更多关联平衡及姿势控制。

**区分性预测**

1. Posterior STN high-beta应更稳定地关联pace和rhythm。
2. Central STN活动应表现出不同的balance关联。
3. FOG阳性试次应出现区域特异性的事件前变化，而不是所有STN触点同步发生相同改变。
4. 选择性刺激不同区域，应产生可区分的步态维度效应。
5. 区域信息应在独立队列中提高FOG预测能力。

**反证条件**

- 多中心多触点研究无法重复区域功能差异。
- 区域选择性刺激没有产生不同的步态维度效应。
- 控制患者差异和电极定位后，区域信息不再提供额外预测价值。

目前该假说得到2025年步态启动研究及定向刺激研究的初步支持，但尚缺少区域选择性刺激与事件级电生理相结合的因果验证。[PMID:40709562] [PMID:39475137]

---

### 6.3 H4与H5：PMC-STN alpha增强是代偿，还是病理性过度耦合？

这是目前最值得利用同一实验范式直接区分的竞争性假说。

<text weight="semibold" color="default">H4：PMC-STN alpha耦合的代偿性重组假说</text>

核心观点：

PMC-STN alpha coherence增强可能是其他运动控制通路功能不足后的代偿反应。

患者试图通过增强PMC-STN耦合维持转弯准备和步态控制，但代偿能力不足时仍然发生FOG。

**预测**

- PMC-STN alpha增强更多出现在成功转弯或冻结恢复阶段。
- 较强的有效代偿应与较短冻结时间或较高转弯成功率相关。
- 选择性削弱代偿性耦合应使步态恶化。
- 其作用应受到M1-STN连接完整性的影响。

**反证**

如果耦合越强，冻结持续时间越长，而且选择性抑制该耦合反而改善FOG，则该假说受到否定。

<divider color="subtle"/>

<text weight="semibold" color="default">H5：PMC-STN alpha病理性过度耦合假说</text>

核心观点：

PMC-STN alpha增强可能是病理性过度同步，限制正常运动信息交换，参与冻结期间的运动障碍。

**预测**

- PMC-STN alpha增强应在冻结前或冻结开始时出现。
- 其幅度或持续时间应预测后续冻结严重程度。
- 选择性抑制病理性耦合应减少冻结。
- 增强该耦合应使冻结恶化。

**反证**

- 耦合增强稳定预测更短冻结时间和更好的恢复。
- 选择性抑制耦合导致冻结恶化。
- 冻结前与正常转弯之间不存在可重复的连接差异。

**建议的直接实验：**

同一患者内同步记录PMC、M1和STN，在正常转弯、冻结前、冻结开始、实际冻结及恢复阶段进行比较。

随后进行具有明确方向性假设的选择性网络调节。

单纯的coherence相关分析不能区分H4和H5。

---

### 6.4 H6–H8：FOG究竟是网络负荷、自动化运动还是姿势协调障碍？

这三种假说试图解释为什么FOG可能发生在STN局部beta变化并不一致的情况下。

<text weight="semibold" color="default">H6：分布式网络负荷超过神经储备假说</text>

核心观点：

FOG是基底节、前额叶、SMA、边缘系统、脑干和小脑之间的发作性协调失败。

当运动、认知及情绪信息同时处理时，患者的神经处理储备不足，网络负荷超过阈值后导致步态控制暂时崩溃。

**预测**

- 双任务、焦虑和决策冲突在控制STN beta后仍然增加FOG风险。
- 冻结前出现前额叶、SMA、皮层-STN及脑干网络协调变化。
- 非STN网络指标提供独立预测信息。
- 降低认知负荷可以改善FOG，即使STN平均beta没有明显改变。

**反证**

如果认知及情绪负荷不影响冻结，且STN局部活动能够解释几乎全部冻结风险，那么该模型受到削弱。

这一假说与神经储备或Cross-Talk模型具有联系。[PMID:41865085]

<divider color="subtle"/>

<text weight="semibold" color="default">H7：基底节-SMA自动化运动驱动不足假说</text>

核心观点：

FOG的主要缺陷是内部运动提示及自动步行程序受损，患者更加依赖外部视觉、听觉或节律提示。

SMA-MLR连接增强可能是维持步行的代偿性重组。

**预测**

- 没有外部提示时，步态启动及连续节律行走更加困难。
- 视觉或听觉提示能够相对选择性地改善步态启动和节律。
- SMA、基底节和MLR活动在冻结前出现异常。
- 外部提示能够部分恢复这些网络活动。

**反证**

如果外部提示不能选择性改善步态启动和节律，且SMA-基底节-MLR活动与冻结发生及恢复没有稳定关系，则该假说受到削弱。

<divider color="subtle"/>

<text weight="semibold" color="default">H8：APA-步伐启动及双侧肌肉协调失耦假说</text>

核心观点：

FOG可能源于预期姿势调整（APA）与步伐启动之间的时间耦合异常，并伴随双侧STN活动不对称、步态周期协调异常及下肢拮抗肌共同激活。

**预测**

- 冻结前出现APA与第一步之间的时间关系异常。
- 双侧STN活动不对称程度增加。
- 下肢拮抗肌共同激活增加。
- STN活动与EMG之间的相位关系在冻结前改变。
- 改善APA与步伐启动耦合可以减少FOG，即使平均beta功率不变。

**反证**

如果冻结前APA、双侧STN活动和肌肉协调均无可重复改变，或者选择性改善姿势准备和肌肉交替控制不能改变实际冻结，则该假说受到否定。

这一模型尤其需要同步STN、EMG、测力平台和三维运动学，而不能仅使用LFP与步速的相关性。

---

### 6.5 H9与H10：低频STN-DBS通过什么机制改善FOG？

这是功能神经外科最有转化价值的竞争性机制之一。

<text weight="semibold" color="default">H9：低频刺激通过PPN/MLR通路募集改善FOG</text>

核心观点：

60 Hz等低频STN-DBS可能通过改变电流扩散和纤维募集，影响STN邻近的PPN/MLR及下行步行网络。

**预测**

1. 低频获益与PPN/MLR相关纤维募集或脑干网络变化相关。
2. 特定PPN/MLR连接特征可以预测低频疗效。
3. 即使STN局部beta没有明显变化，只要相关脑干通路得到有效募集，FOG仍可能改善。
4. 定向刺激改变相关纤维募集时，可以在一定程度上复制低频刺激效果。

**反证**

如果低频刺激改善FOG时没有相应的PPN/MLR募集或脑干网络变化，而且局部STN活动可以独立解释全部获益，则该假说受到削弱。

<divider color="subtle"/>

<text weight="semibold" color="default">H10：低频刺激通过STN局部振荡重组改善FOG</text>

核心观点：

低频刺激主要通过重新组织STN局部beta burst、低beta活动、alpha活动及运动相关频段调制改善步态，而不是依赖PPN/MLR电流扩散。

**预测**

1. 低频治疗效果与STN局部beta burst、ERD或其他频段动态变化相关。
2. 局部电生理反应比PPN/MLR结构连接特征更好地预测个体疗效。
3. 不能产生相应局部活动变化的刺激条件，不应稳定改善FOG。
4. 局部STN选择性调节可以在没有明显PPN/MLR募集的情况下改善FOG。

**反证**

如果低频刺激改善FOG时，STN局部活动没有可重复变化，而PPN/MLR募集能够解释治疗效果，则该假说受到削弱。

**区分H9与H10的关键实验：**

同一患者、匹配TEED、尽可能匹配STN局部组织募集的条件下，同时记录：

- STN多触点LFP；
- 刺激组织募集及纤维连接；
- PPN/MLR相关网络活动；
- 客观冻结事件。

然后判断哪一类神经变化先于临床改善，并进行中介分析。

目前动物PPN entrainment结果和人类低频刺激的临床获益尚不能组成完整的人体因果链。[PMID:19811797] [PMID:28529730]

---

### 6.6 H11–H13：患者亚型与刺激时间结构

<text weight="semibold" color="default">H11：多巴胺反应性及非多巴胺能FOG亚型假说</text>

核心观点：

FOG至少包含多巴胺反应性和多巴胺不反应性等不同临床与网络亚型。

前者可能具有不同的STN-小脑和视觉运动网络特征；后者可能涉及更明显的感觉运动网络异常、胆碱能功能下降及疾病进展相关改变。

**预测**

- 两种亚型具有可重复的STN-小脑及STN-皮层连接差异。
- 胆碱能PET等指标能够补充预测左旋多巴抵抗性FOG。
- 药物与刺激之间的交互作用因亚型而不同。
- 多模态亚型模型在独立队列中优于单一临床严重程度指标。

**反证**

如果控制病程和药物剂量后，亚组差异及治疗交互作用无法重复，则该模型受到削弱。

<divider color="subtle"/>

<text weight="semibold" color="default">H12：TBS刺激暂停导致即时病理驱动重新显现假说</text>

核心观点：

间歇性TBS-DBS暂停期间，病理性驱动输入重新显现，导致步态及FOG控制能力即时下降。

**预测**

- 刺激暂停后FOG风险迅速上升。
- 暂停时间越长，冻结风险或相关神经异常越明显。
- 连续刺激具有更稳定的即时症状控制效果。

**反证**

如果足够长的暂停期间没有可重复的症状反弹，或者暂停时间与FOG风险无关，则该假说受到否定。

<divider color="subtle"/>

<text weight="semibold" color="default">H13：TBS长期神经可塑性改善假说</text>

核心观点：

TBS可能通过重复间歇性刺激促进长期神经可塑性，逐渐改善STN及相关运动网络功能。

**预测**

- 数周至数月治疗后，FOG逐渐改善。
- 短暂停止刺激后，部分疗效仍然保留。
- 长期疗效与可测量的神经活动或网络连接变化相关。
- 长期治疗效果可能不同于单日急性交叉试验的结果。

**反证**

如果充分统计效能的长期研究不能发现TBS相对于连续刺激的持续性额外获益，且刺激停止后所有改善立即消失，则该假说受到否定。

目前两种TBS解释都缺少FOG专属的长期随机对照验证。[PMID:40383539]

## 八、其他重要治疗方向及其机制意义

### 8.1 STN+SNr联合刺激：是否存在超出STN单靶刺激的额外获益？

现有证据存在明显冲突。

支持联合刺激的结果包括：

- 6名难治性FOG患者的前瞻性研究发现，增加超低频SNr刺激后，NFOG-Q和GFQ进一步改善。[PMID:41553951]
- 一项纳入8项随机交叉试验、97名患者的Meta分析报告，STN+SNr联合刺激能够改善FOG。[PMID:42968793]

但反对或未能确认额外获益的证据包括：

- 一项纳入10项研究、109名患者的系统综述和Meta分析发现，联合刺激相对于单独STN刺激没有明确的额外FOG获益，Hedges' g=-0.23，95% CI=-1.04至0.59，I²=85.6%，证据确定性极低。[PMID:42909654]
- 2026年多中心探索性对照研究也提示，联合刺激的获益具有患者间差异，病程可能影响治疗响应。[PMID:42860886]

因此，STN+SNr联合刺激可能存在响应者，但尚不能认定其在群体层面稳定优于单独STN刺激。

更重要的是，双靶点刺激同时改变两个区域的神经活动，无法直接分离STN和SNr的独立贡献。

### 8.2 自适应DBS：beta是否真正具有治疗反馈特异性？

目前有两类值得区分的证据。

**基于STN beta功率的闭环刺激**

Petrucci等的单病例研究报告，FOG时间占比在不同条件下分别为：

- DBS关闭：67.7%；
- 常规DBS：2.3%；
- 自适应DBS：1.5%。

[PMID:32634599]

**基于beta burst duration的自适应刺激**

Wilkins等开展了7名患者的随机、双盲先导研究，比较：

- beta burst驱动aDBS；
- 连续DBS；
- 随机间歇刺激。

不同开启刺激策略均能改善部分步态指标和冻结时间，但开启策略之间没有显著差异。[PMID:40677701]

这项研究对H1有重要意义：

即使beta burst与FOG有关，也不意味着基于beta burst的反馈策略一定优于不依赖该生物标志物的刺激策略。

因此，闭环刺激的临床获益可能来自：

1. beta特异性神经反馈；
2. 刺激强度或时间组织的变化；
3. 减少持续刺激带来的其他不利影响；
4. 上述机制共同作用。

目前不能确定哪一种机制占主导。

### 8.3 连续步态改善不等于FOG改善

这一点对今后的DBS临床研究尤其重要。

Cui等2026年研究18名STN-DBS患者，发现STN刺激能够改善步态序列效应，并减少原地踏步任务中的冻结时间。[PMID:40992964]

但是，步态速度、步幅、节律、平衡、运动启动和实际冻结事件是不同的结局维度。

Guo等网络Meta分析也观察到总体运动评分和步速改善，但FOG-Q没有获得统计学显著改善。[PMID:41659700]

因此：

**不能用UPDRS-III总分改善、步速增加或TUG改善替代实际FOG发作减少的证据。**

研究应分别报告：

- 冻结次数；
- 冻结持续时间；
- 冻结时间占比；
- 冻结诱发概率；
- 步态速度和步幅；
- 步态节律及变异性；
- 平衡与姿势控制。

## 九、证据缺口与下一步研究建议

综合现有证据，我认为最重要的研究任务不是继续增加单一频段的相关性研究，而是建立能够区分竞争性机制的实验体系。

### 9.1 第一优先级：建立事件锁定的多模态同步记录队列

<badge color="success">最高优先级</badge>

目前最缺乏的是大样本、跨任务、能够同时观察冻结前后神经活动的研究。

建议在同一患者中同步记录：

- 双侧STN多触点LFP；
- 皮层EEG或ECoG；
- 下肢多组拮抗肌EMG；
- IMU；
- 三维步态运动学；
- 测力平台及姿势控制指标。

实验任务应包括：

1. 正常直线行走；
2. 步态启动；
3. 原地踏步；
4. 转弯；
5. 门洞通行；
6. 双任务行走；
7. 实际冻结及恢复。

必须使用统一的事件标注体系：

| 事件阶段 | 分析窗口 | 主要研究问题 |
|---|---|---|
| 正常基线 | 稳定步行 | 正常STN步态编码 |
| Pre-FoG | 冻结发生前 | 是否存在提前预测信号 |
| FoG onset | 冻结开始 | 哪些活动变化与冻结启动同步 |
| FoG ongoing | 冻结持续期 | 哪些活动与冻结维持相关 |
| Recovery | 冻结恢复 | 哪些网络变化与有效步行重新出现相关 |

特别需要解决临床冻结标注时间与神经信号变化之间的时间偏差。

### 9.2 第二优先级：解决beta功率与beta burst的冲突

应在同一患者、同一任务中同时比较：

- 低beta和高beta；
- 绝对功率和相对功率；
- ERD/ERS；
- burst duration；
- burst occupancy；
- burst时间分布；
- burst timing entropy。

尤其建议扩大2026年转弯研究的患者样本。

重点进行：

**Pre-FoG-Turn与Pre-Regular-Turn的直接比较。**

不能仅仅分别证明两个条件与Walking存在显著差异，就推断两个条件之间也存在显著差异。

还应检验：

- 预冻结异常能否跨任务预测实际冻结；
- 转弯冻结与步态启动冻结是否共享同一beta特征；
- beta异常是否在控制运动学后仍然存在；
- 不同beta指标是否具有独立预测价值。

### 9.3 第三优先级：直接区分H4与H5

目前PMC-STN alpha耦合的代偿性和病理性解释仍然无法区分。

建议在同一患者中直接比较：

- 正常转弯；
- Pre-FoG-Turn；
- FoG-Turn；
- 冻结恢复。

同时记录PMC、M1和STN。

主要分析：

- PMC-STN alpha coherence；
- M1-STN alpha coherence；
- SMA-STN theta-alpha coupling；
- 冻结持续时间；
- 转弯成功率；
- 恢复时间。

进一步通过选择性网络调节，观察增强或抑制耦合对实际冻结的影响。

这是将单纯相关性研究推进到因果研究的重要一步。

### 9.4 第四优先级：区分H9与H10

需要解决低频刺激改善FOG究竟主要来自：

- STN局部振荡重组；
- PPN/MLR相关纤维募集；
- 两者共同作用。

建议开展匹配刺激能量和组织募集条件的随机交叉研究，同时结合：

1. 个体扩散成像；
2. 方向性电极；
3. VTA模型；
4. 多触点STN-LFP；
5. 脑干相关网络测量；
6. 客观FOG事件。

主要终点不应只是FOG-Q，而应包括冻结次数、持续时间和实际冻结概率。

### 9.5 第五优先级：建立FOG患者前瞻性分型队列

建议根据以下变量进行预先分层：

| 分层变量 | 研究目的 |
|---|---|
| 左旋多巴反应性 | 区分多巴胺反应性和抵抗性FOG |
| OFF-FOG与ON-FOG | 区分不同药物状态下的冻结 |
| STN区域及连接 | 识别区域和网络差异 |
| 认知和执行功能 | 检验认知运动交叉干扰 |
| 焦虑和注意 | 检验情绪及认知负荷 |
| 胆碱能相关指标 | 探索非多巴胺能机制 |
| 疾病持续时间 | 评估疾病进展对治疗响应的影响 |

尤其需要验证STN-LFP特征能否在这些亚型内部提供额外预测信息，而不是仅仅识别总体疾病严重程度。

### 9.6 第六优先级：推进因果性闭环DBS研究

建议直接比较：

- beta功率驱动aDBS；
- beta burst驱动aDBS；
- 相位特异性beta调节；
- 基于IMU的外周反馈刺激；
- 随机自适应刺激；
- 常规连续DBS。

研究必须区分：

**检测准确率、冻结提前预测能力和临床治疗效果。**

同时应采用患者独立的训练、测试及外部验证方案。

不能将训练数据中的分类准确率视为临床泛化能力。

### 9.7 第七优先级：开展长期刺激研究

需要专门研究：

- 60 Hz与130 Hz的长期随机比较；
- STN与STN+SNr的长期疗效；
- TBS与连续刺激的数周至数月比较；
- 刺激暂停期间的即时反弹；
- 长期刺激后神经网络变化；
- 疾病进展对最佳刺激条件的影响。

这些研究能够区分即时神经调节、刺激间歇期反弹和长期神经可塑性。

## 十、建议建立的长期证据管理与自主改进体系

考虑到现有证据已经包含大量原始研究、综述、预印本和竞争性机制模型，建议将文献知识组织成可以持续更新的证据网络，而不是静态文献综述。

### 10.1 建立五层知识结构

<box border radius="lg" padding={3} gap={2}>
  <box background="surface-secondary" radius="md" padding={3}>
    **第一层：原始证据**

    PMID/DOI、研究设计、患者数量、任务、药物状态、刺激状态、原始测量及结果。
  </box>
  <box align="center"><icon name="arrow-down" color="secondary"/></box>
  <box background="surface-secondary" radius="md" padding={3}>
    **第二层：单项研究发现**

    例如：FoG-Turn期间低beta ERD缺失；冻结前PMC-STN alpha耦合发生变化。
  </box>
  <box align="center"><icon name="arrow-down" color="secondary"/></box>
  <box background="surface-secondary" radius="md" padding={3}>
    **第三层：跨研究结论**

    例如：beta平均功率不存在统一方向；STN与FOG之间存在任务和阶段依赖性关系。
  </box>
  <box align="center"><icon name="arrow-down" color="secondary"/></box>
  <box background="surface-secondary" radius="md" padding={3}>
    **第四层：机制模型**

    beta状态转换、网络负荷、区域功能分工、姿势协调等。
  </box>
  <box align="center"><icon name="arrow-down" color="secondary"/></box>
  <box background="surface-secondary" radius="md" padding={3}>
    **第五层：可检验假说**

    H1–H13及其预测、反证条件、验证状态和适用患者范围。
  </box>
</box>

每个研究结论必须能够反向追溯至具体原始证据。

例如：

`H1 → C6/C7/C10 → PMID:30196050、DOI:10.21203/rs.3.rs-9617843/v1`

这样，新研究出现后，不需要重新从头阅读全部文献，就可以找到受到影响的旧结论和相关机制假说。

### 10.2 每条证据应保存的关键信息

建议采用统一字段：

| 字段 | 记录内容 |
|---|---|
| 文献标识 | PMID、DOI |
| 证据类型 | 原始研究、综述、Meta分析、预印本、动物研究 |
| 样本 | 独立患者数、试次数、事件数 |
| 临床表型 | FOG亚型、药物反应性 |
| 实验条件 | Med状态、Stim状态、任务类型 |
| 解剖信息 | STN区域、触点、VTA、连接通路 |
| 电生理指标 | 频段、功率、burst、ERD、熵、耦合 |
| 事件阶段 | 正常、冻结前、冻结中、恢复 |
| 临床终点 | FOG-Q、实际冻结次数、持续时间、步态参数 |
| 研究局限 | 样本量、伪迹、统计偏倚、泛化问题 |
| 证据状态 | 直接证据、跨研究推断、假说 |
| 关联假说 | H1–H13 |
| 反证状态 | 已反证、部分反证、尚未检验 |

尤其需要将患者数、试次数和冻结事件数分开保存，防止重复测量被错误地解释为独立样本。

### 10.3 建立新证据触发旧结论重新评价的机制

不应仅仅将新文献追加到数据库末尾。

每条新证据进入后，应自动或人工检查：

1. 是否支持既有结论？
2. 是否与既有结论冲突？
3. 冲突是否来自不同实验任务？
4. 是否存在不同药物或刺激条件？
5. 是否测量了同一种神经活动指标？
6. 是否改变了某个机制假说的预测结果？
7. 是否满足原假说预先规定的反证条件？

例如：

2026年转弯研究发现低beta ERD缺失及burst分布重组后，应提高H1在转弯冻结情境下的证据权重。

但这不能直接推翻Syrkin-Nikolau等报告的冻结期间beta功率下降，因为两者测量的行为状态、指标和任务并不相同。

合理的更新应是：

- H1在转弯冻结情境下得到新的支持；
- H1的跨任务普遍性仍未得到验证；
- H2仍然具有竞争力；
- 后续研究应优先检验两者的区分性预测。

### 10.4 持续自主改进：从发现问题到验证改进

建议采用以下闭环：

<list connector="solid" marker="number" gap={2}>
  <list-item>
    **发现缺陷**

    例如不同研究的beta频段定义不一致，或者将FOG-Q改善误认为实际冻结事件减少。
  </list-item>
  <list-item>
    **分析原因**

    检查任务、药物状态、刺激条件、指标定义、患者分组及统计单位。
  </list-item>
  <list-item>
    **提出改进**

    统一事件标注、频段报告和临床终点；增加患者独立验证。
  </list-item>
  <list-item>
    **独立验证**

    在不同患者或不同研究中心重复分析，检查结果是否保持。
  </list-item>
  <list-item>
    **评估改进效果**

    比较改进前后的预测性能、外部泛化、结果可重复性和证据覆盖程度。
  </list-item>
  <list-item>
    **更新知识与假说**

    更新结论的证据状态、适用范围及反证条件，保留旧版本及其依据。
  </list-item>
</list>

建议特别设置四个长期质量指标：

- 原始文献可追溯率；
- 关键结论的独立重复验证比例；
- 竞争性假说的区分性预测完成率；
- 预测模型在患者独立外部队列中的性能。

这样才能真正实现从文献积累向可验证研究知识体系的转变。

## 十一、最终综合判断

### 11.1 目前哪些结论相对可靠？

| 研究结论 | 证据状态 | 判断 |
|---|---|---|
| STN-DBS能够改变部分患者的FOG | 直接证据 | 较可靠，但患者异质性明显 |
| STN-LFP与实际FOG存在事件级关联 | 直接证据 | 已有多项小样本研究支持 |
| STN beta功率具有统一的FOG相关方向 | 跨研究推断 | 不支持 |
| Beta burst时间结构与FOG有关 | 跨研究推断 | 有较强研究价值，但仍需重复验证 |
| STN-皮层耦合参与FOG状态转换 | 跨研究推断 | 初步支持 |
| Posterior-central STN具有不同步态编码功能 | 跨研究推断 | 有初步支持，缺少因果验证 |
| STN是FOG唯一病理来源 | 机制假说 | 不支持 |
| STN beta是FOG的必要致病因素 | 机制假说 | 尚未证明 |
| 低频刺激通过PPN/MLR改善FOG | 机制假说 | 尚未证明 |
| FOG具有不同临床和网络亚型 | 跨研究推断 | 有支持，但电生理分型尚未建立 |

### 11.2 我认为最值得优先推进的三个研究问题

**第一：STN beta异常究竟是FOG的原因，还是运动状态改变的结果？**

这是整个研究领域最基础的因果问题。

优先比较H1和H2，要求神经异常在时间上先于冻结，并通过选择性干预验证其必要性或因果贡献。

**第二：FOG是否由特定STN区域及其皮层连接网络的动态失协调引起？**

优先比较H3、H4和H5。

尤其需要解释为什么posterior与central STN可能分别关联步态推进、节律和平衡，以及为什么PMC-STN alpha耦合可能同时具有代偿性和病理性解释。

**第三：STN-DBS改善FOG究竟依赖STN局部神经动力学，还是依赖分布式步行网络募集？**

优先比较H9和H10，并结合H11开展患者分层。

这是最有希望直接改善功能神经外科刺激靶点、接触点和参数选择的方向。

### 11.3 最终研究观点

我认为，目前领域研究最需要避免的三个过度简化是：

1. 将FOG简化为STN beta功率升高；
2. 将STN-DBS的临床疗效等同于STN局部神经活动的因果作用；
3. 将不同患者、不同任务和不同冻结阶段的结果合并成单一机制。

现有证据更支持一个动态、多层次的解释：

**FOG是具有患者间异质性和行为阶段依赖性的运动网络协调障碍。STN参与步态推进、节律、平衡和运动状态转换，其神经活动可能在部分患者中参与冻结的发生和维持，但具体作用取决于STN区域、频段、时间结构以及与皮层、脑干和外周运动输出网络的协调状态。**

因此，下一阶段研究的核心不应只是寻找一个能够区分Freezers和Non-Freezers的STN生物标志物，而应确定：

- 哪种神经异常在冻结之前出现；
- 哪种异常在实际冻结期间维持；
- 哪种异常是继发结果；
- 哪种异常能够被选择性操纵；
- 哪种神经改变能够真正介导临床冻结减少；
- 哪些患者具有相应的治疗响应特征。

只有完成从事件级关联、独立预测到选择性因果干预的证据链，才能将STN-FOG研究从现象描述推进到可指导个体化DBS治疗的机制研究。

**本报告的核心建议：优先建立多触点STN-LFP、皮层活动、下肢EMG与客观冻结事件同步记录的多中心研究，并以H1/H2、H4/H5及H9/H10三组竞争性机制作为预注册的主要检验对象。**

这将比继续寻找单一平均beta功率阈值，更有可能解释现有研究冲突，并推动功能神经外科的个体化刺激优化。
